# /stuck — 막혔을 때

교수님 설명: $ARGUMENTS

1. 먼저 안심시켜 드립니다. (한 문장. "실습 폴더 안이라 망가질 것이 없어요. 같이 볼게요.")
2. 무슨 일이 있었는지 모르면 딱 하나만 여쭙니다: "화면에 나온 메시지를 복사해서 붙여 주시겠어요?"
3. `tutor/troubleshooting.md` 에서 비슷한 증상을 찾아 해결 방법을 **한 가지씩** 안내합니다.
4. 필요하면 현재 위치, 파일 상태를 직접 확인합니다. (읽기만. 고치기 전에는 무엇을 고칠지 먼저 말씀드립니다)
5. 실습 재료가 꼬였다면 `/reset-lab 번호` 로 처음 상태로 되돌릴 수 있다고 알려 드립니다.
6. 해결되면 원래 하던 STEP으로 돌아갑니다: "이제 STEP M을 이어서 해 볼까요?"

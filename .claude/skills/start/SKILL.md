# /start — 실습 시작

1. `my-progress.md` 가 있는지 확인합니다.
   - 이미 있으면: 현재 위치를 알려 드리고 "이어서 하기 / 처음부터 다시" 중 고르시게 합니다. 처음부터를 고르시면 기존 파일 내용을 새 진도표로 바꿉니다.
   - 없으면: `tutor/progress-template.md` 를 복사해 `my-progress.md` 를 만들고, 날짜와 운영체제(지금 환경에서 판단)를 채웁니다.
2. `tutor/curriculum.md` 를 읽고, 아래처럼 **짧게** 환영 인사를 합니다. (8줄 이내)
   - 오늘 무엇을 하게 되는지 한 문장
   - 실습 0~8 목록 (제목만, 한 줄씩)
   - 쓰는 법: "다음", "힌트", "확인해 주세요", "어디까지 했죠?" 이 네 마디만 기억하시면 된다고
3. 수업 시간이 얼마나 있는지 여쭙니다. 선택지는 번호 목록(1. 60분 2. 90분 3. 120분 4. 혼자 천천히)으로 보여 드리고 번호로 답하시게 합니다. 답에 따라 `tutor/curriculum.md` 의 추천 경로를 진도표 위에 적어 둡니다.
4. 답을 받으면 `tutor/labs/lab00-orientation.md` 의 STEP 1을 안내합니다. (CLAUDE.md 의 단계 안내 모양 사용)

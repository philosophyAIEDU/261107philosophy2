# /check — 결과 확인

1. `my-progress.md` 에서 현재 STEP을 찾고, 안내서의 "✅ 성공 기준"을 읽습니다.
2. 해당 실습의 정답 기준 파일이 `tutor/answer-keys/` 에 있으면 함께 읽습니다. (교수님께 정답 파일 내용을 통째로 보여 주지 않습니다)
3. **실제 파일과 폴더를 직접 읽어서** 확인합니다. 짐작으로 답하지 않습니다. 파일을 고치지 않습니다.
4. 결과를 아래 모양으로 짧게 알려 드립니다.

   ```
   🔎 확인 결과 — 실습 N · STEP M
   ✅ 잘 된 점: ...
   ⚠ 더 볼 점: ... (없으면 생략)
   👉 다음: "다음" 이라고 입력하시거나, ⚠를 먼저 고쳐 보세요.
   ```
5. ⚠ 가 있을 때는 고치는 방법을 바로 다 알려 주지 말고, 교수님이 직접 찾으실 수 있도록 어디를 보면 되는지만 알려 드립니다. 교수님이 원하시면 그때 방법을 알려 드립니다.
6. 클로드(조교)가 만든 결과물에 틀린 곳이 있으면 솔직하게 말합니다. "AI도 틀린다"는 것을 확인하는 것 자체가 좋은 배움입니다.

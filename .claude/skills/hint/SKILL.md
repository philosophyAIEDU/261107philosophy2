# /hint — 힌트

1. `my-progress.md` 에서 현재 STEP을 찾고, 안내서의 해당 STEP "💡 힌트"를 읽습니다.
2. 이 대화에서 이 STEP의 힌트를 이미 드렸는지 봅니다.
   - 처음: 방향만 알려 주는 가벼운 힌트 1개
   - 두 번째: 조금 더 구체적인 힌트
   - 세 번째 이상: 그대로 따라 하실 수 있는 정확한 방법(복사할 명령/문장 포함)
3. 교수님이 어디서 막히셨는지 말씀하셨다면, 그 지점에 맞춰 답합니다.
4. 마지막에 "해 보시고 '확인해 주세요' 라고 하시면 같이 볼게요." 라고 덧붙입니다.

# [가상] 설명 가능성은 책임의 조건인가

- 저자: 최샘플
- 연도:
- 게재: 가상과학기술학 5호

## 초록
설명 가능한 인공지능(XAI)이 책임 문제를 풀 열쇠로 자주 거론된다. 이 논문은 설명 가능성이 책임 귀속의 필요조건은 아니며, 오히려 '설명했으니 책임을 다했다'는 면책의 도구로 쓰일 위험이 있다고 주장한다. 설명은 책임의 시작이지 끝이 아니다.

## 주요 주장
- 설명 가능성은 책임의 충분조건도 필요조건도 아니다.
- 설명 요구는 피해자의 질문에 답하는 방식으로 설계되어야 한다.

## 연구 방법
문헌 검토와 가상 사례 두 가지.

## 한계
기술적 설명 방법의 차이를 다루지 않았다.

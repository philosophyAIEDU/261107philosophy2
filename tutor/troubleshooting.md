# 막혔을 때 — 증상별 해결표

## 설치·실행
| 증상 | 해결 |
|---|---|
| `claude` 을(를) 찾을 수 없음 / command not found | 터미널 창을 **닫고 새로 열기**. 그래도 안 되면 설치 명령 다시 실행 |
| `irm` 이(가) 인식되지 않음 (Windows) | CMD가 아니라 **PowerShell** 에서 실행 (줄 앞에 `PS` 가 있는 창) |
| 로그인 후 사용할 수 없다고 나옴 | 무료 플랜인지 확인 (Pro 이상 또는 Console 계정 필요) |
| 그 외 설치 오류 | `claude doctor` 실행 → 메시지를 복사해 채팅 클로드에 물어보기 → https://code.claude.com/docs/en/troubleshoot-install |

## 폴더·위치
| 증상 | 해결 |
|---|---|
| 실습 도우미가 아니라 보통 클로드처럼 답함 | 실습 폴더 밖에서 실행한 것. `/exit` → `cd ~/claude-lab` → `pwd` → `claude` |
| `cd` 했는데 "찾을 수 없음" | `ls` 로 정확한 이름 확인, **Tab** 자동 완성 사용 |
| 폴더 이름에 띄어쓰기 | 따옴표로 감싸기: `cd "강의 자료"` |
| 클로드가 엉뚱한 폴더 파일을 말함 | `! pwd` 로 위치 확인 |
| `/start` 등 명령이 목록에 없음 | `claude-lab` 폴더에서 실행했는지 확인. `.claude/skills` 폴더가 있는지 `! ls .claude/skills` |

## 클로드 코드 화면
| 증상 | 해결 |
|---|---|
| 클로드가 멈추지 않고 계속 작업함 | **Esc** |
| 화면이 이상하게 멈춤 | `Ctrl + C` (두 번 누르면 종료 → `claude -c` 로 이어서 켜기) |
| 허락 화면에서 잘못 골랐음 | 편집이면 `/rewind` (Esc 두 번). 이동·삭제면 백업 폴더에서 복구 |
| 계획 모드에서 빠져나오고 싶음 | Shift + Tab 으로 표시가 없어질 때까지 |
| 한글 입력이 이상함 | 한/영 키 한 번, 또는 메모장에 써서 복사·붙여넣기 |
| 줄바꿈이 안 됨 | `Shift + Enter`, 안 되면 줄 끝에 `\` 쓰고 엔터 |

## 파일
| 증상 | 해결 |
|---|---|
| CSV 를 엑셀로 열면 한글이 깨짐 | "이 CSV 를 UTF-8 BOM 으로 다시 저장해줘" |
| `.claude` 폴더가 안 보임 | 숨김 폴더. Windows 탐색기: 보기 → 표시 → 숨긴 항목 / Mac: ⌘ + Shift + . |
| 실습 재료가 꼬였음 | `/reset-lab 번호` |
| `! start notepad` 가 안 됨 (Windows) | 탐색기에서 파일을 더블클릭해서 열기 |

## 한 줄 실행 (claude -p)
| 증상 | 해결 |
|---|---|
| 파일을 만들어 달라고 했는데 안 만들어짐 | 끝에 `--permission-mode acceptEdits` 를 붙였는지 확인 |
| 다른 폴더 파일을 못 읽음 | 한 줄 실행은 **지금 폴더 안**만 다룸. 그 폴더로 `cd` 후 실행 |
| Windows 에서 `> 파일` 로 저장했더니 한글이 깨짐 | 클로드에게 파일로 저장하게 하기 (실습 7 STEP 3 방식) |

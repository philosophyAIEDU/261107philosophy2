# 30분 핵심 코스 정답 기준 (실습 도우미 전용 — 교수님께 통째로 보여 주지 않기)

이 코스의 자료는 교수님마다 다릅니다 (STEP 2 에서 교수님 전공으로 새로 만듦).
그래서 숫자 대신 **구조와 규칙**을 기준으로 확인합니다. `/check` 때는 실제 파일을 열어 아래 항목을 봅니다.

## 공통 원칙
- 이 코스는 `!` 명령과 `claude -p` 를 안내하지 않습니다. 파일 확인은 탐색기(Finder)에서 직접 열기, 또는 클로드에게 "열어줘" 라고 부탁하기.
- STEP 2·6 의 가상 자료 만들기는 교수님이 **명시적으로 요청한 가상 자료**이므로 CLAUDE.md 의 "지어내지 않기" 원칙의 예외입니다.
  단, 반드시 `[가상]` 표시, "실습용 가상 자료" 문구, 실존 학자·학술지·DOI 금지를 지킵니다.
- STEP 3 이후(정리표, 수업 자료)는 다시 "자료에 없는 것은 지어내지 않기" 원칙이 그대로 적용됩니다.

## STEP 1 — 기본 명령
- 작업 폴더 이름이 실습 폴더 이름으로 끝남 (`claude-lab` 이 아닌 이름으로 받으셨다면 그 이름이면 성공)
- `/rewind` 후 `practice/express30/hello.md` 가 없어졌는지 확인. 남아 있으면 되돌리기 화면에서 "파일도 되돌리기" 선택지를 다시 안내

## STEP 2 — 가상 자료
- `practice/express30/papers/paper01.md ~ paper06.md` (6개)
- 각 파일: 맨 위 "실습용 가상 자료", 제목 앞 `[가상]`, 저자는 가상 이름
- 일부러 섞은 것: 중복본 1편, 연도 또는 저자 누락 1편, 반대 주장 짝 2편
- ⚠ 실존 학자 이름, 실존 학술지 이름, DOI 가 보이면 교수님께 알리고 바꾸게 안내
- 예비 자료를 쓴 경우: `tutor/samples/express30/papers/` 와 같은 6개 (아래 "예비 자료" 참고)

## STEP 3 — 정리표
- `practice/express30/notes/literature-table.csv`, UTF-8 BOM (첫 3바이트 EF BB BF)
- 열: 파일명, 제목, 저자, 연도, 핵심 주장, 연구 방법, 한계, 수업 활용 포인트, 비고
- 6행 (중복본도 지우지 않고 행으로 남아 있어야 함)
- 누락된 연도·저자 → `[확인 필요]` (그럴듯한 값으로 채웠다면 ⚠ 중요: 교수님께 직접 찾아보시게 안내)
- 중복본 → 비고에 "중복 의심" + 짝 파일명
- 반대 주장 → 비고에 짝 파일명
- `papers/` 원본 메모가 바뀌지 않았는지 (수정 시각이나 내용 확인)

## STEP 4 — 수업 자료
- `practice/express30/class-materials/` 안에 `slides.html`, `speaker-notes.md`, `discussion-quiz.md`
- `slides.html`: 외부 링크(인터넷 글꼴·스크립트) 없이 한 파일, 슬라이드마다 출처 파일명, 맨 위 "실습용 가상 자료로 만든 초안"
- `discussion-quiz.md`: 토론 질문 3개(반대 주장 짝 활용), 퀴즈 3문항 + 정답·해설
- `[확인 필요]` 항목이 슬라이드 본문에 쓰이지 않았는지
- 교수님이 한 군데 이상 고쳐 달라고 요청했는지 (대화로 확인)
- 선택: `slides.pptx` — Python 이 있을 때만. 없으면 건너뛴 것이 정상

## STEP 5 — `/lecture-kit` 스킬
- `.claude/skills/lecture-kit/SKILL.md` 가 있고, 앞부분에 `name: lecture-kit` 와 `description:`
- 본문에 들어 있어야 할 것:
  - `$ARGUMENTS` (주제 자리)
  - 정리표 만들기·갱신 → 정리표만 근거로 slides.html / speaker-notes.md / discussion-quiz.md
  - 지어내지 않기, `[확인 필요]`, 출처 표시, 원본 메모 고치지 않기, 지우지 않기
  - 실행 전 계획 보여 주기
  - "초안이며 마지막 확인은 교수님" 문구
- 빠진 규칙이 있으면 "어떤 규칙이 빠졌는지 파일을 다시 읽어 보세요" 정도로만 안내합니다.

## STEP 6 — `/weekly-prep` 자동화
- `.claude/skills/weekly-prep/SKILL.md` 가 있고, 위 다섯 단계(찾기 → 새 행만 추가 → lecture-kit 규칙으로 자료 → inbox 에서 papers 로 옮기기 → 확인 목록)와 "계획 먼저"가 들어 있음
- 실행 후:
  - `inbox/` 가 비었고 `papers/` 에 8개 (paper07, paper08 추가)
  - 정리표 8행. 기존 6행은 그대로, 새 2행 추가. 연도가 빠진 1편은 `[확인 필요]`
  - `class-materials/` 아래에 새 주제의 자료
  - 삭제된 파일 없음 (papers 8개 + 정리표 + 수업 자료)
- 삭제 명령이 허락 화면에 나왔다면 교수님이 거절하셨는지 여쭤보기

# 실습 3. 폴더 정리 — 백업 · 계획 · 실행 · 검증

- ⏱ 약 25분
- 준비: 실습 2 (허락 화면, Shift+Tab)
- 실습 폴더: `practice/03-folder-cleanup/lecture-materials` (뒤죽박죽 강의자료 40개가 미리 들어 있습니다)
- 이번 실습을 마치면:
  - 정리 전에 **직접 백업**하는 습관을 갖습니다.
  - **계획 모드**로 계획을 먼저 검토하고 고친 뒤 실행할 수 있습니다.
  - 결과를 **숫자와 눈으로 검증**하고 기록을 남깁니다.
  - 폴더별 업무 매뉴얼 `CLAUDE.md` 를 만들어 봅니다.

> ⚠ 이 실습은 가상 자료로만 합니다. 실제 강의 폴더는 오늘 실습을 다 해 보신 뒤, 백업을 해 두고 적용해 주세요.

**정리 4단계: ① 백업 → ② 계획 → ③ 실행 → ④ 검증·기록**
클로드 코드는 ③을 빠르게 해 줍니다. ①②④는 교수님의 판단 근육입니다.

### STEP 2/8 — [직접] 백업: 이건 꼭 교수님 손으로

🎯 왜 하나요?
`/rewind` 는 파일 **이동·이름 바꾸기**를 완전히 되돌리지 못할 수 있습니다. 그래서 정리 전 백업은 도구에 맡기지 않고 직접 합니다. 이번에는 **클로드를 잠깐 끄고**, 터미널에서 직접 해 봅니다.

👉 이렇게 해 보세요
1. 클로드 코드 끄기:
```
/exit
```
2. 터미널에서 위치 확인 (끝이 `claude-lab` 인지):
```
pwd
```
3. 폴더 통째로 복사 (Windows PowerShell · Mac 모두 같은 명령):
```
cp -R practice/03-folder-cleanup/lecture-materials practice/03-folder-cleanup/lecture-materials-backup
```
4. 확인:
```
ls practice/03-folder-cleanup
```
5. 클로드를 **하던 대화 그대로** 다시 켜기:
```
claude -c
```
(`-c` = continue, 마지막 대화 이어서)

✅ 성공 기준: `practice/03-folder-cleanup` 안에 `lecture-materials` 와 `lecture-materials-backup` 두 폴더가 있다.

💡 힌트
- 명령이 길어서 오타가 나기 쉽습니다. `practice/03` 까지 치고 **Tab** 을 누르면 나머지가 자동 완성됩니다.
- Windows에서 `cp` 는 `Copy-Item` 의 줄임말입니다. `Copy-Item practice/03-folder-cleanup/lecture-materials practice/03-folder-cleanup/lecture-materials-backup -Recurse` 도 같습니다.
- `claude -c` 대신 `claude` 로 켜도 괜찮습니다. 진도는 `my-progress.md` 에 남아 있습니다.

### STEP 3/8 — 계획 모드로 계획 먼저 보기

👉 이렇게 해 보세요
1. `Shift + Tab` 을 눌러 화면 아래가 **plan mode on** 이 되게 합니다.
2. 아래 요청을 붙여넣으세요.
```
practice/03-folder-cleanup/lecture-materials 폴더를 정리하고 싶어. 아직 실행하지 말고 계획만 세워줘.
- 주차별 폴더(week01 ~ week15)로 나누기
- 파일 이름 규칙: 주차_자료유형_제목.txt  예) week03_slides_공리주의.txt
  자료유형은 slides / quiz / reading / assignment / notice
- 중복으로 보이는 파일은 지우지 말고 _duplicates 폴더로 모으기
- 주차를 알 수 없는 파일은 _unsorted 폴더로
- 파일 이름과 내용의 주차가 다르면 스스로 정하지 말고 '확인 필요'로 표시
바꾸기 전/후 파일 이름을 표로 보여줘.
```

✅ 성공 기준: 클로드가 파일을 바꾸지 않고, 전/후 표가 담긴 계획을 보여 주었다.

💡 힌트
- 계획 모드에서는 클로드가 파일을 읽기만 합니다. 마음 놓고 물어보세요.
- 요청 맨 앞에 `/plan` 을 붙여도 계획 모드로 요청할 수 있습니다.

### STEP 4/8 — [직접] 계획 검토하고 고치기

🎯 왜 하나요?
실행 전 몇 분의 검토가 사고를 막습니다. **무엇을 기준으로 정리할지는 사람이 정합니다.**

👉 이렇게 해 보세요
계획을 읽으며 체크해 보세요.
- □ 주차 판단이 맞나요? 파일 이름과 내용이 다른 파일을 어떻게 다뤘나요?
- □ 중복이라고 판단한 근거가 타당한가요? (완전히 같은 것 vs 수정본)
- □ **삭제** 작업이 계획에 들어 있지 않나요?
- □ 학생에게 보이면 안 되는 파일이 섞여 있지는 않나요?
- □ 내 습관에 맞는 이름 규칙인가요?

고칠 점은 그대로 말하면 됩니다. 예)
```
자료유형에 'activity'(수업 활동지)도 추가해줘. 그리고 '공지'는 주차 폴더 말고 _notices 폴더에 모아줘.
```
→ 계획이 다시 나옵니다. 마음에 들 때까지 반복하세요. **최소 한 번은 고쳐 보세요.**

✅ 성공 기준: 계획을 한 번 이상 고쳐 달라고 요청했다.

💡 힌트
- '수정본'과 '원본'이 진짜 중복일까요? 둘 다 남겨야 할 수도 있습니다.
- `중간고사_문제_초안` 같은 파일은 어떻게 표시하고 싶으신가요?

### STEP 5/8 — 실행: 허락 화면 읽으며 진행

👉 이렇게 해 보세요
1. 계획이 마음에 들면 클로드가 진행 방법을 묻습니다. 처음에는 **편집마다 직접 확인하며 진행**하는 쪽을 고르세요. (문구 예: "Yes, and manually approve edits")
2. 허락 화면이 나오면 어떤 명령인지 읽고 승인합니다.
   - ⚠ `rm`, `del`, `Remove-Item` (삭제 명령)이 보이면 일단 **아니오**!
     ```
     삭제하지 말고 _duplicates 로 옮겨줘
     ```
3. 너무 빨라서 불안하면 **Esc** 로 멈추고 물어보세요.
```
지금까지 뭘 했는지 요약해줘
```

✅ 성공 기준: `lecture-materials` 안에 week 폴더와 `_duplicates`, `_unsorted` 폴더가 생겼다.

💡 힌트
- 파일 옮기기는 비슷한 명령이 여러 번 반복됩니다. 같은 종류의 명령이 계속 나와 번거로우면 "이번 세션 동안 묻지 않기"를 골라도 됩니다. 단, **이동 명령인지 꼭 확인한 다음에.**
- 작업 모드를 계획 모드에서 기본 모드로 바꾸라는 안내가 나오면 따라 주세요.

### STEP 6/8 — 검증: 숫자로, 그리고 눈으로

👉 이렇게 해 보세요
1. 숫자 검증 — 확인은 클로드에게 맡기되 **기준은 교수님이** 정합니다.
```
정리 결과를 검증해줘.
- 백업 폴더(lecture-materials-backup)의 파일 개수와 정리 후 파일 개수가 같은지
- 백업에는 있는데 정리 후 사라진 파일이 있는지 (내용으로 대조)
- 이름 규칙을 안 지킨 파일 목록
- '확인 필요'로 표시한 파일 목록
```
2. [직접] 눈으로 검증 — 탐색기/파인더로 `lecture-materials` 를 열어서
   - □ 무작위로 파일 3개를 열어 들어간 주차 폴더가 맞는지
   - □ `_unsorted`, `_duplicates` 안을 직접 보고 최종 판단

✅ 성공 기준: 파일 수가 40개로 같고, 사라진 파일이 없다. 교수님이 직접 3개 이상 열어 보았다.
(실습 도우미에게 "확인해 주세요" 라고 하시면 제가 한 번 더 봐 드립니다)

💡 힌트
- 클로드의 판단이 틀린 파일이 있다면 그것이 오늘의 수확입니다. 근육 체크 때 이야기해 주세요.

### STEP 7/8 — 기록 남기기 + 우리 폴더의 매뉴얼(CLAUDE.md)

🎯 왜 하나요?
다음 학기에 같은 일을 할 때 **같은 규칙을 다시 설명하지 않아도** 되게 합니다.

👉 이렇게 해 보세요
1. 정리 기록:
```
이번 정리 내역을 practice/03-folder-cleanup/cleanup-log.md 로 만들어줘.
날짜, 정리 규칙, 바뀐 파일 목록(전→후), 내가 확인해야 할 파일 목록을 포함해서.
```
2. 폴더 매뉴얼:
```
cleanup-log.md 의 규칙을 바탕으로 practice/03-folder-cleanup/CLAUDE.md 를 만들어줘.
파일 이름 규칙, 폴더 구조, '파일은 절대 삭제하지 말고 _duplicates 로 옮긴다'는 원칙을 넣어줘. 15줄 이내로.
```
3. 클로드 코드가 지금 어떤 매뉴얼(메모리)을 읽고 있는지 보기:
```
/memory
```
(목록을 확인했으면 Esc 로 닫기)

✅ 성공 기준: `cleanup-log.md` 와 `practice/03-folder-cleanup/CLAUDE.md` 가 생겼다.

💡 힌트
- `CLAUDE.md` 는 조교에게 주는 **업무 매뉴얼**입니다. 클로드 코드는 작업 폴더의 CLAUDE.md 를 자동으로 읽습니다. (지금 이 실습 도우미도 맨 위 폴더의 CLAUDE.md 에 적힌 대로 움직이고 있어요!)
- ⚠ CLAUDE.md 에는 학생 개인정보나 비밀번호를 적지 마세요.

### STEP 8/8 — 🏋️ 근육 체크

👉 [직접] 하나씩 여쭤봅니다.
1. 클로드가 세운 계획에서 내가 **고친 부분**은 무엇이었나요?
2. 클로드의 판단(주차, 중복)이 **틀린 파일**이 있었나요? 왜 틀렸을까요?
3. 내 실제 폴더에 적용한다면, 어떤 폴더 '하나'부터 해 보고 싶나요?

> 정리는 AI가 빠르게 하지만, '무엇을 기준으로 정리할지'는 사람이 정합니다. 좋은 규칙을 세우는 힘, 그게 근육입니다.

📋 실제 내 폴더에 적용할 때 체크리스트
- □ 정리할 폴더 **하나만** 정했다 (문서 폴더 전체 ✗)
- □ 백업을 **내 손으로** 만들었다
- □ 그 폴더로 `cd` 하고 `pwd` 로 확인한 뒤 `claude` 를 실행했다
- □ 계획 모드로 계획을 먼저 읽고 고쳤다
- □ 삭제 대신 **옮기기**로 요청했다
- □ 학생 개인정보 파일(성적, 명단)은 대상에서 뺐다 → 소속 대학 AI 활용 지침 확인
- □ 정리 후 직접 열어 확인하고 기록을 남겼다

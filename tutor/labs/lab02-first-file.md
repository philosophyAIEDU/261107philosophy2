# 실습 2. 첫 파일 — 만들기·고치기·거절·되돌리기

- ⏱ 약 15분
- 준비: 실습 1
- 실습 폴더: `practice/02-first-file`
- 이번 실습을 마치면:
  - 클로드가 파일을 만들거나 고치기 전에 **허락을 구하는 화면**을 읽고 고를 수 있습니다.
  - `@파일이름` 으로 파일을 콕 집어 말할 수 있습니다.
  - 거절하기, 되돌리기(`/rewind`), 작업 모드 바꾸기(Shift+Tab)를 해 봅니다.

---

### STEP 1/7 — 내 수업 소개 파일 만들기

🎯 왜 하나요?
클로드 코드는 채팅과 달리 **내 컴퓨터에 진짜 파일**을 만듭니다. 그래서 만들기 전에 꼭 허락을 구합니다.

👉 이렇게 해 보세요
아래 문장의 `[ ]` 부분을 **교수님의 실제 수업**으로 바꿔서 입력하세요. (바꾸기 귀찮으시면 그대로 입력하셔도 됩니다)
```
practice/02-first-file 폴더에 내 수업 소개 파일을 course-intro.md 로 만들어줘.
과목은 [철학과 비판적 사고], 대상은 [1학년 30명],
핵심 목표는 [AI와 함께 생각하는 힘 기르기]야. 5줄 이내로.
```

허락 화면이 나오면 **내용을 먼저 읽고** `Yes`(예)를 고르세요.
(방향키 ↑↓ 로 고르고 엔터. 문구는 버전에 따라 조금 다를 수 있습니다)

✅ 성공 기준: `practice/02-first-file/course-intro.md` 파일이 생겼다.

💡 힌트
- 허락 화면에는 보통 세 가지가 있습니다: ① 예 ② 이번 세션 동안 묻지 않기 ③ 아니오(다르게 해 달라고 말하기). 처음에는 ①을 고르세요.
- 실제 학생 이름 같은 개인정보는 넣지 마세요.

---

### STEP 2/7 — [직접] 내 눈으로 열어 보기

🎯 왜 하나요?
"만들었습니다"라는 말보다 **파일을 직접 여는 것**이 확인입니다. 이 습관이 오늘 실습의 절반입니다.

👉 이렇게 해 보세요
- Windows:
```
! start notepad practice/02-first-file/course-intro.md
```
- Mac:
```
! open -e practice/02-first-file/course-intro.md
```
읽어 보신 뒤 메모장(텍스트 편집기)을 닫으세요. (메모장을 닫아야 클로드 화면으로 돌아오는 경우가 있습니다)

✅ 성공 기준: 파일을 열어 내용을 직접 읽었다.

💡 힌트
- `.md` 는 '마크다운'이라는 글 형식입니다. 그냥 메모장 글이라고 생각하시면 됩니다. `#` 은 제목, `-` 는 목록 표시예요.
- 안 열리면 탐색기/파인더에서 파일을 더블클릭해도 됩니다.

---

### STEP 3/7 — 고치기: 무엇이 바뀌는지 보기

👉 이렇게 해 보세요
```
@practice/02-first-file/course-intro.md 에 '평가 방식: 과정 중심 평가' 한 줄을 추가해줘
```
- `@` 를 치면 파일 목록이 나와서 고를 수 있습니다. `@cour` 까지 치고 Tab 을 눌러 보세요.

이번 허락 화면에는 **바뀌는 줄**이 표시됩니다. (`+` 초록 = 추가, `-` 빨강 = 삭제)

✅ 성공 기준: 허락 화면에서 추가되는 줄을 확인하고 승인했다. 파일에 '평가 방식' 줄이 있다.

💡 힌트
- `@파일` 은 "이 파일 말이야" 하고 손가락으로 가리키는 것과 같습니다. 파일이 많아질수록 유용합니다.

---

### STEP 4/7 — 거절해 보기

🎯 왜 하나요?
**결정권은 교수님께 있습니다.** 거절하면 실행되지 않는다는 것을 직접 확인해 봅니다.

👉 이렇게 해 보세요
```
practice/02-first-file/course-intro.md 를 지워줘
```
허락 화면이 나오면 **`No`(아니오)** 를 고르세요. 그리고 이어서 이렇게 입력해 보세요.
```
지우지 말고, 대신 파일 맨 아래에 '작성일: 오늘 날짜'를 추가해줘
```

✅ 성공 기준: 파일이 지워지지 않고 그대로 있으며, 맨 아래에 작성일이 추가되었다.

💡 힌트
- 아니오를 고른 뒤 "대신 이렇게 해 줘" 하고 방향을 바꿔 주는 것이 클로드 코드를 잘 쓰는 요령입니다.

---

### STEP 5/7 — 되돌리기 (/rewind)

🎯 왜 하나요?
클로드가 고친 결과가 마음에 안 들 때, **고치기 전으로 되돌리는** 기능이 있습니다.

👉 이렇게 해 보세요
1. 일부러 마음에 안 드는 수정을 시킵니다 (승인하세요):
```
course-intro.md 의 모든 문장을 아주 딱딱한 공문서 말투로 바꿔줘
```
2. 이제 되돌립니다. **Esc 를 두 번 빠르게** 누르거나 아래를 입력하세요.
```
/rewind
```
3. 되돌아갈 지점(방금 그 요청 직전)을 고르고, **코드(파일)까지 되돌리기**를 선택하세요.

✅ 성공 기준: course-intro.md 가 공문서 말투로 바뀌기 전 상태로 돌아왔다.

💡 힌트
- 선택지 문구 예: "Restore code and conversation"(파일과 대화 모두 되돌리기). 버전마다 조금 다릅니다.
- ⚠ 한계: `/rewind` 는 클로드가 **편집한 파일**을 되돌립니다. 파일 **이동·삭제**처럼 명령으로 한 일은 되돌리지 못할 수 있습니다. 그래서 실습 3부터는 **백업을 직접** 합니다.

---

### STEP 6/7 — 작업 모드 3가지 (Shift + Tab)

🎯 왜 하나요?
상황에 따라 "매번 물어봐 / 편집은 그냥 해 / 계획만 세워" 를 바꿀 수 있습니다.

👉 이렇게 해 보세요
`Shift + Tab` 을 한 번씩 누르면서 화면 아래 상태 표시줄이 어떻게 바뀌는지 보세요.

| 표시 | 뜻 | 언제? |
|---|---|---|
| (표시 없음) 기본 | 바꿀 때마다 허락을 구함 | **처음엔 늘 이것** |
| accept edits on | 파일 편집은 묻지 않고 진행 | 익숙하고, 백업이 있을 때 |
| plan mode on | 파일을 건드리지 않고 계획만 보여 줌 | 큰 작업 전에 (실습 3) |

마지막에는 다시 **기본 모드**로 돌려 두세요.

✅ 성공 기준: 세 가지 모드를 모두 보았고, 지금은 기본 모드(표시 없음)다.

💡 힌트
- 문구는 버전마다 조금 다를 수 있습니다. 세 번 누르면 한 바퀴 돌아옵니다.
- ⚠ 허락 화면을 읽는 그 몇 초가 **판단 근육을 쓰는 시간**입니다. 익숙해지기 전까지는 기본 모드를 유지하세요.

### STEP 7/7 — 🏋️ 근육 체크

👉 [직접] course-intro.md 를 다시 열어 보고 답해 주세요. (하나씩 여쭤봅니다)
1. 클로드가 쓴 문장 중 우리 수업과 **맞지 않는 표현**이 있나요?
2. 내가 직접 고친다면 어느 문장을, 왜 고치고 싶나요?

✅ 성공 기준: 두 질문에 답했다.

> AI는 그럴듯한 문장을 '확률'로 만듭니다. 우리 수업을 아는 사람은 교수님뿐이에요.

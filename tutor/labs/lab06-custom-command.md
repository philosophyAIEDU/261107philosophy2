# 실습 6. 나만의 명령 — /weekly-notice 만들기

- ⏱ 약 15분
- 준비: 실습 5 (공지문 요청 형식). 실습 5를 건너뛰셨어도 할 수 있습니다.
- 만들 파일: `.claude/skills/weekly-notice/SKILL.md`
- 이번 실습을 마치면:
  - 자주 쓰는 긴 요청을 **스킬**(나만의 `/명령`)로 저장할 수 있습니다.
  - 스킬 파일을 직접 읽고 고칠 수 있습니다.

> 비유: 조교에게 업무 절차서를 한 번 써 주고, 다음부터는 "**매주 하는 그 일 해 줘**" 한 마디로 맡기는 것.
> 사실 지금 쓰고 계신 `/next`, `/hint` 도 이 폴더에 들어 있는 스킬입니다!

---

### STEP 1/6 — 스킬이 뭔지 들여다보기

👉 이렇게 해 보세요
지금 실습 도우미가 쓰는 스킬 하나를 열어 보세요.
```
! start notepad .claude/skills/hint/SKILL.md
```
(Mac: `! open -e .claude/skills/hint/SKILL.md`)

보이는 구조:
```
---
name: hint                 ← /hint 라는 이름
description: ...           ← 언제 쓰는 명령인지 한 줄 설명
---
(그 아래) 클로드가 따라 할 절차를 우리말로 적은 것
```

✅ 성공 기준: 스킬 파일을 열어 보고, "그냥 우리말로 쓴 업무 절차서구나" 를 확인했다.

💡 힌트: 프로그래밍 언어가 아닙니다. 조교에게 쓰는 메모처럼 **우리말로** 쓰면 됩니다.

---

### STEP 2/6 — 클로드에게 스킬 만들어 달라고 하기

👉 이렇게 해 보세요
```
이 폴더에서 쓸 스킬을 만들어줘.
위치: .claude/skills/weekly-notice/SKILL.md
이름: weekly-notice
하는 일: 내가 주차 번호를 주면(예: /weekly-notice 3)
  practice/05-notices/syllabus.md 를 읽고 실습 5와 같은 형식으로
  practice/05-notices/notices/weekNN_notice.md 를 만들거나 새로 고침.
  형식: 제목 [철학과 비판적 사고] N주차 안내 / 이번 주 주제 / 미리 읽어 올 자료 / 과제·마감 / 한 줄 생각 질문
  말투: 1학년에게 하는 따뜻한 존댓말, 7줄 이내
  계획서에 없는 정보는 [확인 필요]로 표시.
  주차 번호가 없거나 1~15가 아니면 다시 물어보기.
```

✅ 성공 기준: `.claude/skills/weekly-notice/SKILL.md` 파일이 생겼다.

💡 힌트: 만들어지는 파일에는 `$ARGUMENTS` 라는 글자가 들어 있을 거예요. `/weekly-notice 3` 이라고 치면 그 자리에 `3` 이 들어갑니다.

### STEP 5/6 — [직접] 스킬 고쳐 보기: 규칙은 내가 바꾼다

🎯 왜 하나요?
스킬은 **교수님이 직접 고칠 수 있는 글**입니다. 학기마다, 과목마다 조금씩 바꿔 쓰면 됩니다.

👉 이렇게 해 보세요
1. 메모장으로 `SKILL.md` 를 열어 규칙 한 줄을 **직접** 바꾸고 저장하세요. 예)
   - "7줄 이내" → "5줄 이내"
   - "한 줄 생각 질문" 아래에 "수업 전에 떠올려 볼 나의 경험 한 가지" 추가
```
! start notepad .claude/skills/weekly-notice/SKILL.md
```
2. 다시 실행해서 바뀐 규칙이 반영되는지 보세요.
```
/weekly-notice 9
```

✅ 성공 기준: 교수님이 직접 고친 규칙이 새 공지문에 반영되었다.

💡 힌트: 반영이 안 되면 `/exit` → `claude -c` 후 다시 실행.

### STEP 6/6 — 응용 아이디어 + 🏋️ 근육 체크

같은 방법으로 만들어 볼 만한 명령:
| 명령 | 하는 일 |
|---|---|
| `/submission-check 과제2` | 실습 4의 제출 현황표 만들기를 과제 이름만 바꿔 실행 |
| `/cleanup-week 5` | 실습 3의 정리 규칙으로 5주차 자료 정리 |
| `/meeting-summary` | 회의록 → 결정 사항·할 일 표 (보너스 B1) |

👉 [직접] 근육 체크 (하나씩 여쭤봅니다)
1. 스킬로 만들면 편해지는 **내 업무**는 무엇인가요?
2. 그 스킬에 꼭 넣어야 할 **안전 규칙 한 줄**은? (예: "삭제하지 말 것", "점수는 매기지 말 것")

📝 참고: 스킬은 이 폴더(`.claude/skills/`)에 두면 이 폴더에서만, 내 홈 폴더의 `~/.claude/skills/` 에 두면 어느 폴더에서든 쓸 수 있습니다.

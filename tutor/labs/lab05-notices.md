# 실습 5. 공지문 15개 — 강의계획서 한 장으로

- ⏱ 약 15분
- 준비: 실습 2 (`@파일`)
- 실습 폴더: `practice/05-notices` (`syllabus.md` — 가상 강의계획서. **일부러 빈칸이 있습니다**)
- 이번 실습을 마치면:
  - 파일 하나로 같은 형식의 문서 여러 개를 **한꺼번에** 만듭니다.
  - AI가 빈칸을 그럴듯하게 지어내는 경향을 직접 보고, `[확인 필요]` 원칙으로 막는 법을 익힙니다.
  - 여러 파일을 한 번에 고칩니다.

> **교수님 업무**: 매주 LMS 공지문을 비슷한 형식으로 새로 쓰기
> **자동화 후**: 계획서 하나로 15주 공지문 초안을 한꺼번에 → 교수님은 `[확인 필요]` 칸만 채우기

---

### STEP 1/6 — [직접] 빈칸 찾기 게임

🎯 왜 하나요?
AI에게 맡기기 전에, **AI가 지어낼 만한 곳**을 먼저 짐작해 두면 검증이 훨씬 쉬워집니다.

👉 이렇게 해 보세요
```
! start notepad practice/05-notices/syllabus.md
```
(Mac: `! open -e practice/05-notices/syllabus.md`)

계획서를 훑어보며 **정보가 비어 있거나 '추후 공지'인 곳**을 찾아보세요. 몇 군데인가요? 찾은 주차를 저에게 말씀해 주세요.

✅ 성공 기준: 교수님이 빈칸이라고 생각하는 주차를 말씀하셨다. (정답은 마지막에 같이 맞춰 봅니다)

💡 힌트: 읽기자료 칸, 과제 마감 날짜, 휴강·보강 정보를 보세요.

---

### STEP 2/6 — 15주 공지문 한 번에 만들기

👉 이렇게 해 보세요
```
@practice/05-notices/syllabus.md 를 바탕으로 practice/05-notices/notices 폴더에 주차별 공지문 15개를 만들어줘.
파일 이름은 week01_notice.md ~ week15_notice.md.
형식:
- 제목: [철학과 비판적 사고] N주차 안내
- 이번 주 주제 / 미리 읽어 올 자료 / 과제·마감 / 한 줄 생각 질문
- 말투: 1학년에게 하는 따뜻한 존댓말, 7줄 이내
- 계획서에 없는 날짜나 정보는 지어내지 말고 [확인 필요]라고 표시
```
파일 15개를 만드는 허락이 차례로 나옵니다. 첫 한두 개는 내용을 읽어 보고, 괜찮으면 "이번 세션 동안 묻지 않기"를 골라도 됩니다.

✅ 성공 기준: `practice/05-notices/notices` 에 공지문 15개가 생겼다.

💡 힌트: 마지막 줄 **"지어내지 말고 [확인 필요]라고 표시"** 가 이 실습의 핵심입니다.

---

### STEP 3/6 — 검증: [확인 필요] 모아 보기

👉 이렇게 해 보세요
1. 클로드에게 모아 달라고 하기:
```
notices 폴더에서 [확인 필요] 가 들어간 곳만 주차별로 목록으로 보여줘
```
2. [직접] 아래 공지문은 직접 열어서 계획서와 대조해 보세요.
   - □ 4주차 (휴강) — 보강 날짜를 지어내지 않았나요?
   - □ 8주차 (중간고사) — 날짜·범위가 계획서와 같나요?
   - □ 11주차 — 읽기자료는 어떻게 되어 있나요?
   - □ 15주차 (기말 발표) — 발표 시간이 계획서와 같나요?
3. STEP 1에서 짐작한 빈칸과 비교해 보세요. 몇 개 맞히셨나요?

✅ 성공 기준: [확인 필요] 목록을 보았고, 4·8·11·15주차를 직접 대조했다.

---

### STEP 4/6 — 실험: "지어내지 마" 한 줄이 없으면?

🎯 왜 하나요?
규칙 한 줄의 힘을 눈으로 확인합니다.

👉 이렇게 해 보세요
```
@practice/05-notices/syllabus.md 를 보고 11주차 공지문을 practice/05-notices/test_week11.md 로 하나 만들어줘. 읽기자료와 과제 안내를 꼭 넣어줘.
```
만들어진 `test_week11.md` 와 `notices/week11_notice.md` 를 비교해 보세요.
- 계획서에 **없는** 읽기자료나 과제를 그럴듯하게 써 넣었나요?

✅ 성공 기준: 두 파일을 비교해 보았다. (지어냈는지 아닌지는 매번 다를 수 있습니다. 그 '다를 수 있음'이 바로 확률입니다)

💡 힌트: 비교가 번거로우면 "두 파일의 차이를 표로 비교해줘" 라고 하세요.

---

### STEP 5/6 — 한 번에 고치기

👉 이렇게 해 보세요
1. [직접] 빈칸을 교수님이 채워서 알려 주세요. 예)
```
11주차 읽기자료는 '강의 자료실의 AI 윤리 기사 2편'이고, 4주차 보강은 아직 미정이야. 해당 공지문에 반영해줘.
```
2. 15개 공지문 전체를 한 번에 바꾸기. 예)
```
notices 폴더의 공지문 15개 모두 맨 아래에 '질문은 강의 게시판 Q&A에 남겨 주세요.' 한 줄을 추가해줘
```

✅ 성공 기준: 11주차가 반영되었고, 15개 파일 모두 마지막 줄이 추가되었다.

💡 힌트: "모두", "전부" 같은 말로 여러 파일을 한꺼번에 고칠 수 있습니다. 결과는 무작위로 2~3개 열어 확인!

---

### STEP 6/6 — 🏋️ 근육 체크

👉 [직접] 하나씩 여쭤봅니다.
1. '한 줄 생각 질문' 중 우리 학생들에게 **맞지 않는 질문**이 있었나요? 어떻게 바꾸고 싶나요?
2. AI가 빈칸을 지어낼 수 있다는 걸 알고 나니, 다른 업무에서 조심해야 할 곳은 어디일까요?

> AI는 빈칸을 그럴듯하게 채웁니다. **"지어내지 말고 [확인 필요]로 표시"** 를 습관처럼.

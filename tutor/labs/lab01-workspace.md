# 실습 1. 작업실 확인 — 클로드는 어디서 일할까?

- ⏱ 약 10분
- 준비: 실습 0
- 이번 실습을 마치면:
  - 클로드 코드가 '실행한 폴더'를 작업실로 삼는다는 것을 압니다.
  - 클로드 안에서 `!` 로 터미널 명령(pwd, ls)을 쓸 수 있습니다.
  - 멈추기(Esc), 새로 시작(`/clear`)을 할 수 있습니다.

> 비유: 조교에게 "연구실 3번 책장만 정리해 줘"라고 **방을 정해 주는 것**과 같습니다.

---

### STEP 1/5 — 지금 내 위치 확인하기

🎯 왜 하나요?
클로드는 터미널에서 `claude` 를 실행한 그 폴더 안의 파일을 다룹니다. 그래서 "지금 어디에 있는지"를 아는 것이 안전의 첫걸음입니다.

👉 이렇게 해 보세요
입력 칸 맨 앞에 느낌표 `!` 를 붙이면, 클로드에게 묻지 않고 **터미널 명령을 바로 실행**합니다.
```
! pwd
```
(`pwd` = "지금 어느 방에 있지?")

✅ 성공 기준: 끝이 `claude-lab` 으로 끝나는 경로가 나왔다.
(예: Windows `C:\Users\이름\claude-lab`, Mac `/Users/이름/claude-lab`)

💡 힌트
- `!` 를 치면 입력 칸 모양(색)이 바뀝니다. 그다음 `pwd` 를 쓰고 엔터.
- 경로 끝이 `claude-lab` 이 아니라면: `/exit` 로 나간 뒤 `cd ~/claude-lab` → `claude` 로 다시 실행하세요.

⚠ 흔한 문제: 다른 폴더(예: 홈 폴더 전체)에서 실행하면 클로드가 내 문서 전체를 작업 범위로 봅니다. 실습은 꼭 `claude-lab` 안에서!

---

### STEP 2/5 — 방 안에 뭐가 있나 둘러보기

👉 이렇게 해 보세요
1. 터미널 명령으로 목록 보기:
```
! ls
```
(`ls` = "이 방에 뭐가 있지?")

2. 이번에는 클로드에게 말로 물어보기:
```
이 실습 폴더에는 어떤 폴더들이 있고, 각각 어떤 실습에 쓰이는지 표로 간단히 알려줘
```

✅ 성공 기준: `practice`, `tutor` 등의 폴더 목록을 보았고, 클로드가 폴더 설명을 표로 답했다.

💡 힌트
- `! ls` 는 명령 실행, 그냥 문장은 클로드에게 질문. 둘의 차이를 느껴 보세요.
- 결과가 길면 마우스 휠로 위로 올려 볼 수 있습니다.

---

### STEP 3/5 — 탐색기/파인더로 같은 폴더 열어 보기

🎯 왜 하나요?
터미널은 '다른 세계'가 아니라 **같은 폴더를 글자로 다루는 창**일 뿐입니다. 눈으로 확인해 두면 안심이 됩니다.

👉 이렇게 해 보세요
- Windows:
```
! explorer .
```
- Mac:
```
! open .
```
(점 `.` 은 '지금 이 폴더'라는 뜻)

✅ 성공 기준: 탐색기/파인더 창이 열려서 `practice`, `tutor` 폴더가 보였다.

💡 힌트
- 창이 뒤에 숨어 있을 수 있어요. 작업 표시줄(Dock)을 확인해 보세요.
- `.claude` 처럼 점으로 시작하는 폴더는 숨겨져 보입니다. Windows 탐색기: 보기 → 표시 → 숨긴 항목 / Mac 파인더: ⌘ + Shift + . (마침표)

---

### STEP 4/5 — 멈추기 연습 (Esc)

🎯 왜 하나요?
클로드가 생각보다 길게, 엉뚱하게 일할 때 **언제든 멈출 수 있다**는 것을 알면 마음이 편합니다.

👉 이렇게 해 보세요
1. 일부러 긴 일을 시켜 봅니다:
```
철학과 비판적 사고 수업에서 쓸 사고실험 30개를 아주 자세히 설명해줘
```
2. 답이 나오기 시작하면 **Esc** 키를 한 번 누르세요.

✅ 성공 기준: Esc 를 눌러 클로드가 중간에 멈추는 것을 보았다.

💡 힌트
- Esc 한 번 = 지금 하던 일 멈추기. 대화는 그대로 남습니다.
- 비상 버튼: `Ctrl + C` 도 멈춥니다. 단, **두 번 연달아** 누르면 클로드 코드가 꺼집니다. 꺼져도 괜찮아요. `claude -c` 로 다시 켜면 하던 대화가 이어집니다.

---

### STEP 5/5 — 새로 시작하기 (/clear) 와 정리

🎯 왜 하나요?
주제가 바뀔 때는 대화를 비우는 것이 좋습니다. 대화가 길어질수록 클로드가 예전 이야기를 섞기 쉽기 때문입니다. **파일은 지워지지 않고 대화만 비워집니다.**

👉 이렇게 해 보세요
1. 지금은 실습 도우미가 진도를 `my-progress.md` 에 적어 두었으니 안심하고 비워도 됩니다.
```
/clear
```
2. 그리고 이렇게 입력하세요:
```
어디까지 했죠?
```

✅ 성공 기준: `/clear` 후에도 실습 도우미가 진도표를 보고 "실습 1 마지막 단계"라고 알려 주었다.

📝 실습 1 정리
| 입력 | 뜻 |
|---|---|
| `! 명령` | 터미널 명령을 바로 실행 (`! pwd`, `! ls`) |
| Esc | 지금 하던 일 멈추기 |
| `/clear` | 대화 비우고 새로 시작 (파일은 그대로) |
| `/exit` | 클로드 코드 끄기 |
| `claude -c` | (터미널에서) 마지막 대화 이어서 켜기 |

★ 클로드 코드 실행 3단계 습관: **① cd 로 이동 → ② pwd 로 확인 → ③ claude 실행**

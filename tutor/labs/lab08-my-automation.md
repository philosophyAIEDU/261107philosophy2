# 실습 8. 내 업무 설계 — 나만의 자동화 초안

- ⏱ 약 10분
- 준비: 실습 0의 근육 체크 메모 (`my-progress.md` 의 '나의 메모')
- 실습 폴더: `practice/08-my-automation`
- 이번 실습을 마치면:
  - 내 실제 반복 업무를 **자동화 설계 시트**로 정리할 수 있습니다.
  - 설계 시트로 **나만의 스킬 초안**을 만들어 학교로 가져갑니다.

---

### STEP 1/4 — 설계 시트 채우기 (인터뷰)

🎯 왜 하나요?
자동화의 실력은 도구보다 **규칙을 글로 분명히 쓰는 힘**에 있습니다. 오늘 배운 모든 실습이 사실 이 시트의 빈칸을 채운 것이었어요.

👉 이렇게 해 보세요
```
나만의 자동화 설계를 도와줘. 아래 설계 시트 항목을 하나씩 나에게 질문해 줘. 한 번에 하나씩만 묻고, 내 답을 기다려 줘.
① 반복하는 업무 ② 얼마나 자주, 몇 개 ③ 입력(어떤 파일에서 시작) ④ 출력(어떤 파일이 나와야)
⑤ 규칙(이름, 형식, 기준) ⑥ 애매할 때는 나에게 넘길지, 규칙대로 처리할지 ⑦ 내가 검증할 방법
⑧ 개인정보가 들어가는지
다 끝나면 practice/08-my-automation/design-sheet.md 로 정리해줘.
```
(실습 0에서 적어 둔 메모가 있다면, 그 업무로 시작하세요)

✅ 성공 기준: `practice/08-my-automation/design-sheet.md` 가 생겼다.

💡 힌트 — 교수님들이 많이 자동화하시는 업무
- 학기 말 강의자료 폴더 정리 및 다음 학기용 복사
- 매주 공지문·리마인드 메일 초안
- 학생 질문 모음 → 주차별 FAQ 문서 (보너스 B2)
- 회의록 파일들 → 결정 사항·할 일 목록 (보너스 B1)
- 여러 논문 메모 → 주제별 문헌 정리표 (보너스 B4)

⚠ ⑧에서 개인정보가 들어간다면: 소속 대학 지침 확인 / 가명 처리 / 대상에서 제외 중 하나를 꼭 정하세요.

### STEP 2/4 — 설계 시트로 스킬 초안 만들기

👉 이렇게 해 보세요
```
@practice/08-my-automation/design-sheet.md 를 바탕으로 스킬 초안을 practice/08-my-automation/my-skill/SKILL.md 로 만들어줘.
안전 규칙을 꼭 넣어줘: 삭제하지 말고 옮기기, 애매한 것은 [확인 필요]로 넘기기, 없는 정보 지어내지 않기.
```

✅ 성공 기준: `practice/08-my-automation/my-skill/SKILL.md` 가 생겼다.

💡 힌트: 이 초안은 아직 `/명령` 으로 쓸 수 없습니다. 연습장에 둔 것이에요. 실제로 쓰는 법은 STEP 3에서.

---

### STEP 3/4 — [직접] 학교에서 실제로 써 보는 순서

👉 아래 순서를 읽고, 궁금한 점을 물어보세요.
1. 내 컴퓨터에 업무용 폴더를 하나 정합니다. 예) `~/work/weekly-notice`
2. 그 폴더에 실제 자료를 **복사**해 넣습니다. (원본은 그대로 두기 = 백업)
3. 스킬 초안을 그 폴더의 `.claude/skills/스킬이름/SKILL.md` 로 복사합니다.
   (어느 폴더에서든 쓰고 싶다면 홈 폴더의 `~/.claude/skills/스킬이름/SKILL.md`)
4. `cd` → `pwd` → `claude` → `/스킬이름` 으로 실행
5. 처음 세 번은 **계획 모드**로 먼저 보고, 결과를 반드시 직접 확인합니다.

✅ 성공 기준: 순서를 읽었고, 내 업무에 적용할 첫 폴더를 정했다.

### STEP 4/4 — 🏋️ 마지막 근육 체크

👉 [직접] 하나씩 여쭤봅니다.
1. 오늘 클로드의 결과에서 **내가 직접 고친 부분**은 무엇이었나요?
2. 자동화하면서 '시간이 줄어든 일'과 '오히려 더 신경 써야 했던 일'은?
3. 아낀 시간을 **학생들과의 어떤 시간**에 쓰고 싶나요?

> 자동화의 목적은 일을 없애는 것이 아니라, 교수님만 할 수 있는 일에 쓸 시간을 버는 것입니다.

📝 오늘 익힌 클로드 코드
| 기능 | 실습 |
|---|---|
| 이동·확인·실행 (`cd`, `pwd`, `claude`), `!` 명령, Esc, `/clear` | 1 |
| 허락 화면, `@파일`, 거절, `/rewind`, Shift+Tab 모드 | 2 |
| 백업, 계획 모드, `claude -c`, 폴더별 `CLAUDE.md`, `/memory` | 3 |
| 대조·표 만들기, 애매한 것은 사람에게 | 4 |
| 일괄 생성·일괄 수정, `[확인 필요]` 원칙 | 5 |
| 스킬(나만의 `/명령`), `$ARGUMENTS` | 6 |
| `claude -p`, `--permission-mode acceptEdits` | 7 |
| 자동화 설계 시트 | 8 |

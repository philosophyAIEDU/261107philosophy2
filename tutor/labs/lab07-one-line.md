# 실습 7. 한 줄 자동화 — claude -p

- ⏱ 약 10분
- 준비: 실습 4 (`submission-status.csv`). 실습 4를 건너뛰셨다면 STEP 2의 '대체 문장'을 쓰세요.
- 실습 폴더: `practice/04-submissions`
- 이번 실습을 마치면:
  - 대화창에 들어가지 않고 **터미널 한 줄**로 클로드에게 일을 맡길 수 있습니다.
  - 결과를 바로 **파일로** 받을 수 있습니다.

> `-p` 는 "질문 하나 처리하고, 결과만 내놓고, 끝내기" 라는 뜻입니다. (print)
> 이 한 줄을 메모해 두면 다음 과제 때 그대로 다시 쓸 수 있고, 나중에 '정해진 시간에 자동 실행'으로 넓혀 갈 수 있습니다.

### STEP 2/5 — 터미널 한 줄로 물어보기

👉 이렇게 해 보세요 (터미널에서, `practice/04-submissions` 폴더)
```
claude -p "submission-status.csv 를 읽고 미제출자와 지각자 명단만 짧게 정리해줘"
```
- 실습 4를 건너뛰셨다면 대체 문장:
```
claude -p "roster.csv 와 submissions 폴더를 비교해서 미제출자 명단만 짧게 알려줘"
```

✅ 성공 기준: 대화창이 열리지 않고, 답만 출력된 뒤 다시 터미널 입력 상태로 돌아왔다.

💡 힌트
- 따옴표(`"`)를 앞뒤로 꼭 짝 맞춰 주세요.
- `claude` 를 찾을 수 없다고 나오면 터미널을 새로 열고 다시 이동하세요.

### STEP 3/5 — 결과를 파일로 받기

🎯 왜 하나요?
결과가 화면에서 사라지지 않고 **파일로 남으면**, 메일·LMS에 바로 쓸 수 있습니다.

👉 이렇게 해 보세요
```
claude -p "submission-status.csv 를 읽고 미제출자와 지각자 명단을 follow-up.md 파일로 저장해줘. 학생별로 보낼 짧은 안내 문장 초안도 함께." --permission-mode acceptEdits
```
- `--permission-mode acceptEdits` = "이번 한 번은 파일 만들기를 허락해 둘게" 라는 뜻입니다. 한 줄 실행에는 허락 화면이 나오지 않기 때문에, 미리 허락 범위를 정해 주는 것입니다.

그리고 [직접] 열어 보기:
- Windows: `notepad follow-up.md`
- Mac: `open -e follow-up.md`

✅ 성공 기준: `practice/04-submissions/follow-up.md` 가 생겼고, 교수님이 직접 열어 읽었다.

💡 힌트
- Mac 에서는 결과를 `> follow-up.md` 로 바로 저장하는 방법도 있습니다. (`claude -p "…" > follow-up.md`)
  Windows PowerShell 에서는 이 방법이 한글을 깨뜨릴 수 있어서, 위처럼 클로드에게 직접 저장하게 하는 방법을 권합니다.
- ⚠ 허락을 미리 줄 때는 **읽기·만들기처럼 안전한 일**에만. 이동·삭제 작업에는 쓰지 마세요.

### STEP 4/5 — 나만의 '한 줄 모음' 만들기

👉 이렇게 해 보세요
자주 쓸 한 줄을 메모장에 모아 두면, 다음 학기에도 복사해서 붙여넣기만 하면 됩니다.
```
claude -p "이 폴더에 my-one-liners.md 를 만들고, 미제출자·지각자 명단을 뽑는 claude -p 명령 두 가지(화면 출력용, 파일 저장용)와 각각의 설명을 적어줘. 다음 과제 때 과제 이름만 바꿔 쓰는 방법도 한 줄 적어줘." --permission-mode acceptEdits
```

✅ 성공 기준: `practice/04-submissions/my-one-liners.md` 가 생겼다.

💡 힌트: 한 줄 실행에서 클로드는 **지금 터미널이 있는 폴더 안에서만** 파일을 만들 수 있습니다. (실습 1의 '작업실' 원칙 그대로!)

💡 한 걸음 더 (오늘은 하지 않아요)
- Windows '작업 스케줄러', Mac 'cron' 에 이 한 줄을 등록하면 **매주 월요일 9시에 자동 실행**할 수 있습니다.
- ⚠ 유료 구독 플랜에서 `claude -p` 사용량은 2026년 6월 15일부터 대화형 사용량과 별도의 월간 크레딧에서 차감됩니다. (자세한 내용: support.claude.com 의 Agent SDK 크레딧 안내)

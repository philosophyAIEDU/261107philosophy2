### STEP B1 — 회의록 4개 → 결정 사항·할 일 표

- 실습 폴더: `practice/bonus-1-meetings` (가상 학과 회의록 4개)

👉 이렇게 해 보세요
```
practice/bonus-1-meetings 의 회의록 4개를 읽고 practice/bonus-1-meetings/summary.md 를 만들어줘.
1) 결정된 사항 표: 날짜 / 결정 내용
2) 할 일 표: 담당 / 할 일 / 마감 / 상태(완료·진행·미정)
3) 아직 결정되지 않은 안건 목록
회의록에 없는 담당자나 마감은 지어내지 말고 [확인 필요]로.
```
✅ 성공 기준: summary.md 가 생겼고, 교수님이 회의록 1개를 직접 열어 표와 대조했다.
💡 힌트: '학과 세미나' 안건이 회의마다 어떻게 바뀌었는지 따라가 보세요. 마지막 결정이 표에 들어갔나요?
🏋️ 근육 체크: 회의록이 '결정'인지 '의견'인지 애매한 문장이 있었나요?

### STEP B2 — 학생 질문 모음 → 주차별 FAQ

- 실습 폴더: `practice/bonus-2-faq` (`student-questions.csv` — 가상 질문 28개)

👉 이렇게 해 보세요
```
practice/bonus-2-faq/student-questions.csv 를 읽고 주차별 FAQ 문서 practice/bonus-2-faq/faq.md 를 만들어줘.
```

✅ 성공 기준: faq.md 가 생겼고, [교수님 답변 필요] 칸을 직접 채워 보았다.
💡 힌트: "과제1 분량"처럼 계획서에 없는 정보에 클로드가 답을 지어내지 않았는지 보세요.
🏋️ 근육 체크: 자주 나오는 질문은 **수업 설계**에 대해 무엇을 말해 주나요?

### STEP B3 — 과제 피드백 초안 (마지막 한 문장은 교수님이)

- 실습 폴더: `practice/04-submissions` (가상 제출물. 실습 4를 했다면 이름이 정리된 상태)
- ⚠ 가상 제출물로만 연습하세요. 실제 학생 글은 개인정보를 지우고, 학교 지침을 확인한 뒤에만.

👉 이렇게 해 보세요
```
practice/04-submissions/submissions 에서 파일 3개만 골라 practice/04-submissions/feedback 폴더에 피드백 초안을 만들어줘.
파일 이름은 '학번_feedback.md'.
기준: ① 주장이 분명한가 ② 근거가 있는가 ③ 반론을 고려했는가
각 기준마다 잘한 점 1개, 생각해 볼 질문 1개. 점수는 매기지 마.
맨 아래에 '교수님 한마디:' 빈 줄을 남겨줘.
```
✅ 성공 기준: 피드백 3개가 생겼고, 교수님이 '교수님 한마디'를 하나 이상 직접 썼다.
💡 힌트: 처음부터 30개를 다 만들지 말고 3개로 품질을 먼저 확인하세요. 마음에 들면 그때 규칙을 스킬로.
🏋️ 근육 체크: 이 학생이 수업 시간에 어떤 표정이었는지, 지난번보다 무엇이 나아졌는지는 교수님만 아십니다. 그 한 문장에 무엇을 담고 싶으세요?

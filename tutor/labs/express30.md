# 30분 핵심 코스 — 내 전공 자료로 수업 자료까지, 그리고 매주 한 마디로

- ⏱ 약 30분
- 준비: 클로드 코드 설치·로그인 완료, 이 폴더(`claude-lab`)에서 `claude` 실행
- 실습 폴더: `practice/express30` (처음에는 README 하나만 있는 빈 작업장)
- 정답 기준: `tutor/answer-keys/express30.md` (실습 도우미 전용)
- 예비 자료: `tutor/samples/express30/` (자료 만들기가 잘 안 될 때만 씀)
- 이번 코스를 마치면 교수님은 아래 다섯 가지를 직접 해 보시게 됩니다.
  - **기본 명령**: 작업실 확인, 작업 모드, 멈추기, `/` 목록, `@파일`, 되돌리기
  - **가상 자료 만들기**: 내 전공 분야의 가상 논문 메모 6편
  - **정리**: 문헌 정리표 (엑셀에서 열리는 CSV)
  - **수업 자료**: 강의 슬라이드(HTML, 원하면 .pptx) + 발표자 노트 + 토론 질문·퀴즈
  - **스킬과 자동화**: `/lecture-kit` (수업 자료 만들기) → `/weekly-prep` (새 자료가 들어오면 한 마디로 전부 처리)

> **교수님 업무**: 읽을거리를 정리하고, 그것으로 매주 슬라이드와 토론 질문을 만들기
> **자동화 후**: 새 논문 메모를 `inbox` 폴더에 넣고 `/weekly-prep` 한 마디 → 정리표 갱신 + 다음 주 수업 자료 초안 → 교수님은 **검토와 판단**만

> ⚠ 이 코스의 논문은 모두 **가상**입니다. 실존 학자·학술지·DOI 를 쓰지 않고, 제목 앞에 `[가상]` 을 붙입니다. 가상 자료를 실제 수업이나 연구에 인용하지 마세요. 실제 자료로 해 보실 때는 원문을 직접 확인하고, 저작권과 소속 대학의 AI 활용 지침을 먼저 살펴 주세요.

**뼈대: ① 기본 명령 → ② 자료 만들기 → ③ 정리 → ④ 수업 자료 → ⑤ 스킬로 저장 → ⑥ 자동화**
클로드 코드는 만들고 정리하는 일을 빠르게 해 줍니다. 무엇이 맞는지, 무엇을 수업에 쓸지는 교수님의 판단입니다.

> (실습 도우미에게) 이 코스는 터미널 명령(`!`)과 한 줄 실행(`claude -p`)을 쓰지 않습니다. 교수님은 클로드에게 **말로 요청**하고, 결과는 **탐색기(Mac: Finder)에서 직접 열어** 확인하십니다. 파일 열기를 클로드에게 부탁하시면 열어 드려도 됩니다.

### STEP 1/7 — 기본 명령 연습 (⏱ 4분)

🎯 왜 하나요?
클로드는 실행된 폴더 안의 파일을 **실제로** 만들고 바꿉니다. 일을 맡기기 전에 ① 어느 방에서 일하는지, ② 어떤 방식으로 일하게 할지, ③ 잘못되면 어떻게 멈추고 되돌리는지를 먼저 손에 익힙니다.

👉 이렇게 해 보세요
1. 작업실 확인 — 아래를 입력하세요. 답의 끝이 실습 폴더 이름(`claude-lab`)이면 맞습니다.
```
지금 어느 폴더에서 일하고 있는지 한 줄로 알려줘
```
2. 작업 모드 — `Shift + Tab` 을 한 번씩 누르며 화면 아래 표시가 바뀌는 것을 보세요. 마지막에는 **기본(표시 없음)**으로 돌려 두세요.

| 표시 | 뜻 | 언제? |
|---|---|---|
| (표시 없음) 기본 | 파일을 바꿀 때마다 허락을 구함 | **처음엔 늘 이것** |
| accept edits on | 파일 편집은 묻지 않고 진행 | 익숙하고 백업이 있을 때 |
| plan mode on | 파일을 건드리지 않고 계획만 보여 줌 | 큰 작업 전에 (STEP 3) |

3. 명령 목록 — 입력 칸에 `/` 하나만 쳐 보세요. 쓸 수 있는 명령 목록이 뜹니다. `Esc` 로 닫습니다.
4. `@파일` — `@` 를 치고 파일 이름 앞부분을 치면 파일을 골라 짚을 수 있습니다.
```
@practice/express30/README.md 를 세 줄로 요약해줘
```
5. 멈추기와 되돌리기 — 아래를 입력하고 허락 화면에서 승인한 뒤, `/rewind` 를 입력해 방금 만든 파일을 되돌려 보세요.
```
practice/express30/hello.md 파일을 만들고 "안녕하세요" 한 줄만 적어줘
```
   - 클로드가 답을 쓰는 도중에 `Esc` 를 누르면 언제든 멈춥니다.

✅ 성공 기준: 작업 폴더를 확인했고, 세 가지 모드를 본 뒤 기본 모드로 돌려 두었으며, `@파일` 요청과 `/rewind` 되돌리기를 한 번씩 해 보았다.

💡 힌트
- 폴더 이름이 실습 폴더가 아니라면: `/exit` 로 나간 뒤 터미널에서 실습 폴더로 이동해 `claude` 를 다시 실행하세요. (README ③ 단계)
- `/rewind` 화면에서는 되돌아갈 지점(방금 요청)을 고르고, "코드(파일)도 되돌리기"에 해당하는 선택지를 고릅니다. 문구는 버전마다 조금 다릅니다.
- 모드 문구도 버전마다 조금 다를 수 있습니다. 세 번 누르면 한 바퀴 돌아옵니다.

### STEP 2/7 — 내 전공으로 가상 자료 만들기 (⏱ 5분)

🎯 왜 하나요?
연습은 가상 자료로 합니다. 그런데 남의 분야 자료로는 재미도, 검증할 눈도 생기지 않습니다. 그래서 **교수님 전공 분야의 가상 논문 메모**를 직접 만들어 씁니다. 교수님은 전문가이기 때문에 "그럴듯하게 틀린 것"을 가장 잘 알아보실 수 있습니다.

> (실습 도우미에게) 이 STEP 을 시작할 때 먼저 **"전공 과목(또는 강의 과목)과 다음 주 수업 주제를 알려 주세요"** 하고 여쭤보세요. 답을 들은 뒤, 아래 요청의 `[ ]` 를 교수님 답으로 채운 문장을 코드블록으로 드립니다.

👉 이렇게 해 보세요
1. 실습 도우미의 질문에 전공 과목과 주제를 답하세요. (예: "교육학 — 형성평가", "경영학 — 플랫폼 전략")
2. 실습 도우미가 채워 드린 요청을 복사해 붙여 넣으세요. 모양은 이렇습니다.
```
practice/express30/papers 폴더에 [전공 과목]의 [수업 주제]에 관한 가상 논문 메모 6편을 만들어줘.
- 파일 하나에 한 편, 파일 이름은 paper01.md ~ paper06.md
- 각 메모: 제목, 저자, 연도, 초록(3~4문장), 주요 주장, 연구 방법, 한계
- 제목 앞에 반드시 [가상] 을 붙이고, 파일 맨 위에 "실습용 가상 자료" 라고 적기
- 실존 학자·학술지·DOI 는 쓰지 말고, 저자는 '김가상' 처럼 가상 이름으로
- 연습용으로 이런 것을 섞어줘: 같은 논문의 중복본 1편, 연도나 저자가 빠진 메모 1편, 서로 반대되는 주장을 하는 메모 2편
```
3. [직접] 탐색기(Mac: Finder)에서 `practice/express30/papers` 폴더를 열고, 메모 두세 개를 더블클릭해 읽어 보세요.
   - □ 내 분야답게 그럴듯한가요?
   - □ `[가상]` 표시가 다 있나요?
   - □ 전문가로서 "이건 이상한데" 싶은 곳이 있나요? 있다면 그곳이 오늘의 첫 번째 발견입니다.

✅ 성공 기준: `practice/express30/papers` 에 메모 6개가 생겼고, 교수님이 직접 두세 개를 열어 읽었다.

💡 힌트
- 탐색기를 찾기 어려우면: "practice/express30/papers 폴더를 탐색기로 열어줘" 라고 클로드에게 부탁하세요.
- 자료 만들기가 잘 안 되거나 시간이 없으면: "tutor/samples/express30/papers 의 예비 자료를 practice/express30/papers 로 복사해줘" (철학·윤리 분야 예비 자료)
- 교수님 전공을 말씀하기 곤란하시면 예비 자료로 진행해도 됩니다.

### STEP 3/7 — 가상 자료 정리하기: 계획 먼저, 그다음 실행 (⏱ 5분)

🎯 왜 하나요?
읽을거리가 쌓이면 한 장짜리 정리표가 필요합니다. 큰 작업은 **계획부터 보고** 실행합니다. 그리고 빈칸이나 중복처럼 애매한 것은 클로드가 메우지 않고 교수님께 넘기게 합니다.

👉 이렇게 해 보세요
1. `Shift + Tab` 으로 화면 아래가 **plan mode on** 이 되게 합니다.
2. 아래 요청을 붙여 넣으세요.
```
practice/express30/papers 의 메모를 문헌 정리표로 정리하려고 해. 실행하지 말고 계획만 보여줘.
- 결과: practice/express30/notes/literature-table.csv (엑셀에서 한글이 깨지지 않게 UTF-8 BOM)
- 열: 파일명, 제목, 저자, 연도, 핵심 주장, 연구 방법, 한계, 수업 활용 포인트, 비고
- 메모에 없는 내용은 지어내지 말고 빈칸 대신 [확인 필요] 로 적기
- 중복으로 보이는 메모는 지우지 말고 비고에 "중복 의심: 어느 파일과" 라고 적기
- 서로 반대되는 주장이 있으면 비고에 짝을 적기 (토론 수업에 쓸 것)
- papers 폴더의 원본 메모는 고치지 않기
```
3. 계획을 읽고 마음에 들면 승인합니다. 처음에는 **편집마다 직접 확인하며 진행**하는 쪽을 고르세요.
4. [직접] 정리표를 탐색기에서 더블클릭해 엑셀로 엽니다.
   - □ 메모 2편을 골라 원문과 정리표를 나란히 놓고 대조해 보세요. 원문에 없는 말이 들어갔나요?
   - □ `[확인 필요]` 와 "중복 의심" 이 어디에 있나요?

✅ 성공 기준: `notes/literature-table.csv` 가 생겼고, 교수님이 엑셀로 열어 2편 이상을 원문과 대조했다.

💡 힌트
- 계획에 "삭제" 가 들어 있으면 승인하지 말고 "지우지 말고 비고에만 적어줘" 라고 고쳐 달라고 하세요.
- 엑셀에서 한글이 깨지면: "literature-table.csv 를 UTF-8 BOM 으로 다시 저장해줘"
- 엑셀이 파일을 열고 있으면 클로드가 저장하지 못합니다. 고쳐 달라고 하기 전에 엑셀을 닫아 주세요. (저장할지 물으면 "저장 안 함")

### STEP 4/7 — 수업 자료 만들기 (⏱ 6분)

🎯 왜 하나요?
정리표가 있으면 수업 자료의 뼈대가 이미 있는 셈입니다. 이번에는 **정리표만 근거로** 슬라이드와 토론 질문을 만들게 하고, 모든 슬라이드에 출처를 달게 합니다. 출처가 있어야 교수님이 확인할 수 있습니다.

👉 이렇게 해 보세요
1. 기본 모드인지 확인한 뒤(STEP 1 표), 아래 요청을 붙여 넣으세요.
```
practice/express30/notes/literature-table.csv 만 근거로 다음 주 수업 자료를 practice/express30/class-materials 폴더에 만들어줘.
- slides.html : 강의 슬라이드 10장 내외. 파일 하나로, 인터넷 연결이나 설치 없이 브라우저에서 열리고, 화살표 키로 넘기고, 인쇄하면 한 장에 슬라이드 하나씩 나오게
- 슬라이드마다 아래쪽에 출처(정리표의 파일명) 표시
- speaker-notes.md : 슬라이드별 발표자 노트
- discussion-quiz.md : 토론 질문 3개(반대 주장 짝을 활용)와 확인 퀴즈 3문항(정답과 해설 포함)
- 정리표의 [확인 필요] 항목은 슬라이드에 쓰지 말고, 쓰지 않은 항목을 마지막에 목록으로 알려줘
- 모든 파일 맨 위에 "실습용 가상 자료로 만든 초안" 이라고 적기
```
2. [직접] 탐색기에서 `class-materials/slides.html` 을 더블클릭하면 브라우저에서 열립니다. 화살표 키로 넘겨 보세요.
3. [직접] 마음에 안 드는 곳 **한 군데를 말로 고쳐 달라고** 해 보세요. 예)
```
3번 슬라이드는 글이 너무 많아. 핵심만 세 줄로 줄이고, 줄인 내용은 발표자 노트로 옮겨줘.
```

✅ 성공 기준: `class-materials` 에 `slides.html`, `speaker-notes.md`, `discussion-quiz.md` 가 생겼고, 교수님이 슬라이드를 브라우저로 넘겨 보았으며, 한 군데 이상 고쳐 달라고 요청했다.

💡 선택: PowerPoint(.pptx) 파일로도 받고 싶다면
- 이 방법은 교수님 컴퓨터에 **Python** 이 있어야 합니다. 먼저 물어보세요.
```
이 컴퓨터에 Python 이 설치되어 있는지 확인해줘. 설치는 하지 말고 확인만.
```
- 있다고 하면:
```
방금 만든 슬라이드 내용 그대로 practice/express30/class-materials/slides.pptx 도 만들어줘. 필요한 Python 패키지 설치가 있으면 먼저 무엇을 설치하는지 설명하고 허락을 받아줘.
```
- 허락 화면에 `pip install python-pptx` 가 보이면, PowerPoint 파일을 만드는 도구를 내려받는 명령입니다. 승인해도 됩니다.
- Python 이 없으면 오늘은 HTML 슬라이드로 충분합니다. (브라우저에서 인쇄 → "PDF로 저장" 하면 PDF 슬라이드도 됩니다)

💡 힌트
- 슬라이드가 열리지 않으면: "slides.html 을 브라우저로 열어줘" 라고 부탁하세요.
- 슬라이드 디자인은 말로 얼마든지 바꿀 수 있습니다. ("글씨를 더 크게", "학교 색인 남색 계열로")

### STEP 5/7 — 수업 자료 만드는 과정을 스킬로 저장하기 (⏱ 4분)

🎯 왜 하나요?
STEP 3~4 의 긴 요청을 매주 다시 쓰지 않도록, 조교에게 **업무 절차서**를 한 번 써 두는 것입니다. 이것을 **스킬**이라고 하며, `/명령이름` 한 마디로 부를 수 있습니다. 지금 쓰시는 `/hint`, `/next` 도 이 폴더에 들어 있는 스킬입니다.

👉 이렇게 해 보세요
1. 아래 요청을 붙여 넣으세요.
```
지금까지 한 '정리표 → 수업 자료' 과정을 스킬로 만들어줘.
위치: .claude/skills/lecture-kit/SKILL.md
이름: lecture-kit
하는 일: 내가 주제를 주면(예: /lecture-kit 7주차 형성평가)
  practice/express30/papers 의 메모로 notes/literature-table.csv 를 만들거나 갱신하고,
```

### STEP 6/7 — 자동화: 새 자료가 들어오면 한 마디로 전부 (⏱ 5분)

🎯 왜 하나요?
실제 업무에서는 읽을거리가 매주 조금씩 늘어납니다. 그때마다 "무엇이 새로 들어왔는지 찾고 → 정리표에 더하고 → 수업 자료를 만들고 → 처리한 것을 옮기는" 일을 **스킬 하나가 알아서 하도록** 묶습니다. 스킬이 다른 스킬(`/lecture-kit`)의 규칙을 그대로 쓰게 하는 것이 요령입니다.

👉 이렇게 해 보세요
1. 자동화 스킬을 만듭니다.
```
매주 쓸 자동화 스킬을 하나 더 만들어줘.
위치: .claude/skills/weekly-prep/SKILL.md
이름: weekly-prep
하는 일: /weekly-prep 다음주 주제 (예: /weekly-prep 8주차 피드백)
  1. practice/express30/inbox 폴더에 새로 들어온 메모가 있는지 스스로 찾는다. 없으면 없다고 말하고 멈춘다.
  2. 새 메모만 literature-table.csv 에 추가한다. 기존 행은 바꾸지 않는다.
  3. lecture-kit 스킬의 규칙 그대로 다음 주 주제의 수업 자료를 만든다.
  4. 처리한 메모는 inbox 에서 papers 폴더로 옮긴다. 지우지 않는다.
  5. 마지막에 '교수님이 확인하실 것' 목록을 한 화면으로 보여 준다: 새로 추가된 행, [확인 필요], 중복 의심, 쓰지 않은 항목.
  실행 전에 무엇을 할지 계획부터 보여 준다.
```
2. 시험용으로 "새로 들어온 자료" 를 만듭니다.
```
practice/express30/inbox 폴더에 지난번과 같은 분야, 같은 규칙으로 가상 논문 메모 2편(paper07.md, paper08.md)을 만들어줘. 그중 1편은 연도가 빠지게 해줘.
```
3. 이제 한 마디로 실행합니다. `[ ]` 에 다음 주 주제를 넣으세요.
```

```
4. 계획을 읽고 승인합니다. 허락 화면에서 **옮기기(이동) 명령인지** 확인하고, 삭제 명령(`rm`, `del`, `Remove-Item`)이 보이면 **아니오**를 고른 뒤 "삭제하지 말고 옮기기만 해줘" 라고 말하세요.
5. [직접] 탐색기에서 확인하세요.
   - □ `inbox` 가 비고, `papers` 에 메모가 8개가 되었나요?
   - □ 정리표에 새 행 2개가 늘었나요? 연도가 빠진 메모는 `[확인 필요]` 인가요?
   - □ 새 주제의 수업 자료 폴더가 생겼나요?

✅ 성공 기준: `/weekly-prep` 한 마디로 정리표 갱신, 새 수업 자료, 메모 옮기기가 이루어졌고, 교수님이 탐색기에서 결과를 직접 확인했다.

💡 힌트

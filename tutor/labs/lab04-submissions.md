# 실습 4. 제출 현황표 — 과제 제출물 자동 확인

- ⏱ 약 20분
- 준비: 실습 3 (백업·계획·검증 습관). 실습 3을 건너뛰셨다면 계획 모드(Shift+Tab)만 알면 됩니다.
- 실습 폴더: `practice/04-submissions`
  - `roster.csv` — 가상 수강생 30명 (학생01~학생30)
  - `submissions/` — 과제1 제출 파일 (이름이 제각각)
- 이번 실습을 마치면:
  - 명단과 제출물을 **대조**해서 제출 현황표를 자동으로 만듭니다.
  - 애매한 경우를 AI가 스스로 정하지 않고 **교수님께 넘기도록** 요청하는 법을 익힙니다.

> **교수님 업무**: 마감 후 제출 파일 30개를 하나씩 열어 누가 냈는지, 늦었는지 확인하기
> **자동화 후**: 요청 한 번 → 파일 이름 통일 + 현황표 + 확인 필요 목록 → 교수님은 **검증과 판단**만

> ⚠ 반드시 가상 학생 자료로 연습합니다. 실제 학생 이름·학번·성적을 AI에 넣을 때는 소속 대학의 AI 활용 지침과 개인정보 규정을 먼저 확인해 주세요.

---

### STEP 1/6 — 재료 보기 + [직접] 백업

👉 이렇게 해 보세요
1. 제출 폴더를 열어 파일 이름을 훑어보세요.
   - Windows: `! explorer "practice\04-submissions\submissions"`
   - Mac: `! open practice/04-submissions/submissions`
2. 백업 — 이번에는 클로드를 끄지 않고 `!` 로 직접 합니다. (Windows·Mac 같은 명령)
```
! cp -R practice/04-submissions/submissions practice/04-submissions/submissions-backup
```
3. 확인:
```
! ls practice/04-submissions
```

✅ 성공 기준: `submissions-backup` 폴더가 생겼다.

💡 힌트
- 클로드에게 "백업해 줘"라고 시키는 것도 가능하지만, `!` 로 **내가 직접 친 명령**은 클로드의 판단을 거치지 않습니다. 백업처럼 중요한 일은 내 손으로.
- `! cp` 가 안 되면: `/exit` → 터미널에서 같은 명령(`!` 없이) → `claude -c`

### STEP 2/6 — 계획 모드로 계획 먼저 보기

👉 이렇게 해 보세요
`Shift + Tab` 으로 **plan mode on** 을 켜고 붙여넣으세요.
```
practice/04-submissions 의 과제1 제출물을 roster.csv 와 대조해서 정리하려고 해. 실행하지 말고 계획만 보여줘.
- submissions 폴더 안 파일 이름을 '학번_이름_과제1.txt' 로 통일
- 파일 이름에 학번이 없으면 파일 내용에서 학번을 찾아 판단
- 파일 이름과 내용의 학생 정보가 다르면 이름을 바꾸지 말고 '확인 필요' 목록에 넣기
- 같은 학생이 여러 번 냈으면 지우지 말고 둘 다 남기고 _1, _2 로 표시
- practice/04-submissions/submission-status.csv 만들기
  열: 학번, 이름, 제출여부, 제출일시, 지각여부, 파일명, 비고
  엑셀에서 한글이 깨지지 않게 UTF-8 (BOM) 으로 저장
- 마감: 2026-10-20 23:59 (23:59 제출은 정시로 본다)
```

✅ 성공 기준: 파일을 바꾸지 않고 계획이 나왔다.

💡 힌트
- "23:59 제출은 정시로 본다"처럼 **경계를 미리 정해 주는 것**이 규칙을 잘 쓰는 요령입니다.

---

### STEP 3/6 — [직접] 계획 검토

👉 아래 질문으로 계획을 점검하고, 부족하면 고쳐 달라고 말씀하세요.
- □ 학번을 어떻게 찾는지(파일 이름 / 내용) 설명이 있나요?
- □ 삭제 작업이 없나요?
- □ 애매한 경우를 **스스로 결정하지 않고** 나에게 넘기나요?
- □ 미제출자도 표에 들어가나요? (명단 30명 전체가 표에 있어야 합니다)

✅ 성공 기준: 계획을 읽고 체크리스트를 확인했다. (고칠 것이 있었다면 고쳐 달라고 했다)

💡 힌트: 계획에 미제출자가 빠져 있다면 "명단 30명 전원을 표에 넣고 미제출자는 제출여부를 N으로" 라고 덧붙여 보세요.

---

### STEP 4/6 — 실행

👉 계획을 승인하고, 허락 화면을 읽으며 진행합니다. (이름 바꾸기 명령이 여러 번 나옵니다)

✅ 성공 기준: `submission-status.csv` 가 생겼고, `submissions` 안 파일 이름이 대부분 `학번_이름_과제1.txt` 모양이 되었다.

💡 힌트: 진행 중 불안하면 Esc → "지금까지 바꾼 파일을 표로 보여줘"

### STEP 5/6 — [직접] 검증: 현황표를 엑셀로 열어 보기

👉 이렇게 해 보세요
- Windows:
```
! start practice/04-submissions/submission-status.csv
```
- Mac:
```
! open practice/04-submissions/submission-status.csv
```

엑셀에서 직접 세어 보세요.
- □ 제출 + 미제출 = **30명**인가요?
- □ 지각으로 표시된 학생은 몇 명인가요? 제출일시를 직접 보고 맞는지 확인
- □ 마감 정각(23:59)에 낸 학생은 어떻게 표시되었나요?
- □ 두 번 낸 학생이 표시되었나요?
- □ '확인 필요'로 넘어온 파일이 있나요? 그 파일을 직접 열어 보세요.
- □ 무작위로 파일 3개를 열어 학번·이름이 맞는지

다 보셨으면 "확인해 주세요" 라고 해 주세요. 제가 정답 기준과 한 번 더 대조해 드립니다.

✅ 성공 기준: 교수님이 표를 직접 열어 위 항목을 확인했다.

💡 힌트
- 엑셀에서 한글이 깨지면 클로드에게 "submission-status.csv 를 UTF-8 BOM 으로 다시 저장해줘" 라고 하세요.
- 엑셀이 없으면 메모장(`! start notepad ...`)으로 열어도 됩니다.

### STEP 6/6 — 판단은 교수님 + 🏋️ 근육 체크

🎯 왜 하나요?
30개 파일을 열던 일이 '검증 몇 분'으로 바뀌었습니다. 하지만 **지각을 인정할지, 두 번 낸 것 중 무엇을 채점할지는 교수님이 정합니다.**

👉 [직접] 교수님의 결정을 표에 기록해 보세요. 예)
```
submission-status.csv 에 '교수님결정' 열을 추가해줘.
- 2회 제출 학생: 마지막 제출본을 채점
- 지각 3명: 사유 확인 후 결정 (지금은 '사유 확인 중'으로)
- 확인 필요 파일: [교수님이 확인한 내용]
```

그리고 근육 체크 (하나씩 여쭤봅니다)
1. 클로드가 **스스로 정해 버렸으면 곤란했을** 판단은 무엇이었나요?
2. 다음 과제 때 규칙에 한 줄 더 넣는다면 무엇을 넣고 싶나요?

> 자동화해도 사람이 꼭 확인할 일: 지각 인정 여부, 예외 사정. 자동화하지 않을 일: 학생에 대한 최종 판단.

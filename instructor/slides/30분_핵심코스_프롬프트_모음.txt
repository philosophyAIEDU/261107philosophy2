사용법
- 아래 '----' 사이의 문장을 그대로 복사해 클로드 코드 입력창에 붙여 넣고 Enter.
- [ ] 안은 교수님 내용으로 바꿔 주세요.
- 이 코스의 논문은 모두 가상 자료입니다. 실제 수업이나 연구에 인용하지 않습니다.
- 실습 도우미를 쓰는 말: 다음 / 힌트 / 확인해 주세요 / 어디까지 했죠?
- 결과 파일은 탐색기(Mac: Finder)에서 practice/express30 폴더를 열어 직접 확인합니다.


==================================================================
 시작
==================================================================

[실습 폴더(claude-lab)에서 클로드 코드를 켠 뒤]
----
/lab 30
----
(또는 /start 를 입력하고 "1. 30분 핵심 코스" 를 고릅니다)


==================================================================
 STEP 1. 기본 명령 연습 (4분)
==================================================================

[1] 작업실 확인
----
지금 어느 폴더에서 일하고 있는지 한 줄로 알려줘
----

[2] 작업 모드: Shift + Tab 을 한 번씩 누르며 화면 아래 표시 보기
    (표시 없음) 기본 → accept edits on → plan mode on → 다시 기본

[3] 명령 목록: 입력 칸에 / 하나만 입력 → Esc 로 닫기

[4] @파일로 짚어서 요청
----
@practice/express30/README.md 를 세 줄로 요약해줘
----

[5] 만들고 되돌리기 (허락 화면에서 승인한 뒤 /rewind)
----
practice/express30/hello.md 파일을 만들고 "안녕하세요" 한 줄만 적어줘
----
----
/rewind
----
    답이 나오는 도중에 Esc 를 누르면 언제든 멈춥니다.


==================================================================
 STEP 2. 내 전공으로 가상 자료 만들기 (5분)
==================================================================

[1] 실습 도우미가 전공 과목과 다음 주 수업 주제를 여쭙니다. 답해 주세요.
    예) 교육학 — 형성평가 / 경영학 — 플랫폼 전략

[2] 가상 논문 메모 6편 만들기 ([ ] 를 교수님 답으로)
----
practice/express30/papers 폴더에 [전공 과목]의 [수업 주제]에 관한 가상 논문 메모 6편을 만들어줘.
- 파일 하나에 한 편, 파일 이름은 paper01.md ~ paper06.md
- 각 메모: 제목, 저자, 연도, 초록(3~4문장), 주요 주장, 연구 방법, 한계
- 제목 앞에 반드시 [가상] 을 붙이고, 파일 맨 위에 "실습용 가상 자료" 라고 적기
- 실존 학자·학술지·DOI 는 쓰지 말고, 저자는 '김가상' 처럼 가상 이름으로
- 연습용으로 이런 것을 섞어줘: 같은 논문의 중복본 1편, 연도나 저자가 빠진 메모 1편, 서로 반대되는 주장을 하는 메모 2편
----

[3] [직접] 탐색기에서 practice/express30/papers 를 열고 두세 편 읽어 보기
    □ 내 분야답게 그럴듯한가요?  □ [가상] 표시가 다 있나요?  □ "이건 이상한데" 싶은 곳은?

[막히면] 예비 자료(철학·윤리 분야)로 진행
----
tutor/samples/express30/papers 의 예비 자료를 practice/express30/papers 로 복사해줘
----


==================================================================
 STEP 3. 가상 자료 정리하기 (5분)
==================================================================

[1] Shift + Tab 으로 plan mode on 을 켠 뒤
----
practice/express30/papers 의 메모를 문헌 정리표로 정리하려고 해. 실행하지 말고 계획만 보여줘.
- 결과: practice/express30/notes/literature-table.csv (엑셀에서 한글이 깨지지 않게 UTF-8 BOM)
- 열: 파일명, 제목, 저자, 연도, 핵심 주장, 연구 방법, 한계, 수업 활용 포인트, 비고
- 메모에 없는 내용은 지어내지 말고 빈칸 대신 [확인 필요] 로 적기
- 중복으로 보이는 메모는 지우지 말고 비고에 "중복 의심: 어느 파일과" 라고 적기
- 서로 반대되는 주장이 있으면 비고에 짝을 적기 (토론 수업에 쓸 것)
- papers 폴더의 원본 메모는 고치지 않기
----

[2] 계획에 "삭제" 가 들어 있다면 (예시)
----
지우지 말고 비고에만 적어줘
----

[3] 계획이 마음에 들면 승인 → 편집마다 직접 확인하며 진행

[4] [직접] 정리표를 엑셀로 열어 2편을 원문 메모와 대조

[엑셀에서 한글이 깨지면] (엑셀을 먼저 닫고, 저장할지 물으면 "저장 안 함")
----
literature-table.csv 를 UTF-8 BOM 으로 다시 저장해줘
----


==================================================================
 STEP 4. 수업 자료 만들기 (6분)
==================================================================

[1] 기본 모드로 돌아와서
----
practice/express30/notes/literature-table.csv 만 근거로 다음 주 수업 자료를 practice/express30/class-materials 폴더에 만들어줘.
- slides.html : 강의 슬라이드 10장 내외. 파일 하나로, 인터넷 연결이나 설치 없이 브라우저에서 열리고, 화살표 키로 넘기고, 인쇄하면 한 장에 슬라이드 하나씩 나오게
- 슬라이드마다 아래쪽에 출처(정리표의 파일명) 표시
- speaker-notes.md : 슬라이드별 발표자 노트
- discussion-quiz.md : 토론 질문 3개(반대 주장 짝을 활용)와 확인 퀴즈 3문항(정답과 해설 포함)
- 정리표의 [확인 필요] 항목은 슬라이드에 쓰지 말고, 쓰지 않은 항목을 마지막에 목록으로 알려줘
- 모든 파일 맨 위에 "실습용 가상 자료로 만든 초안" 이라고 적기
----

[2] [직접] 탐색기에서 class-materials/slides.html 더블클릭 → 화살표 키로 넘겨 보기

[3] 한 군데 고쳐 달라고 하기 (예시)
----
3번 슬라이드는 글이 너무 많아. 핵심만 세 줄로 줄이고, 줄인 내용은 발표자 노트로 옮겨줘.
----

[선택] PowerPoint(.pptx) 파일로도 받기 — Python 이 있을 때만
----
이 컴퓨터에 Python 이 설치되어 있는지 확인해줘. 설치는 하지 말고 확인만.
----
----
방금 만든 슬라이드 내용 그대로 practice/express30/class-materials/slides.pptx 도 만들어줘. 필요한 Python 패키지 설치가 있으면 먼저 무엇을 설치하는지 설명하고 허락을 받아줘.
----
    허락 화면에 pip install python-pptx 가 보이면 PowerPoint 파일을 만드는 도구를 받는 명령입니다. 승인해도 됩니다.
    Python 이 없으면 HTML 로 충분합니다. 브라우저에서 인쇄 → "PDF로 저장" 하면 PDF 슬라이드가 됩니다.


==================================================================
 STEP 5. 수업 자료 만드는 과정을 스킬로 저장하기 (4분)
==================================================================

[1] 스킬 만들기
----
지금까지 한 '정리표 → 수업 자료' 과정을 스킬로 만들어줘.
위치: .claude/skills/lecture-kit/SKILL.md
이름: lecture-kit
하는 일: 내가 주제를 주면(예: /lecture-kit 7주차 형성평가)
  practice/express30/papers 의 메모로 notes/literature-table.csv 를 만들거나 갱신하고,
  그 정리표만 근거로 class-materials/주제 이름 폴더에 slides.html, speaker-notes.md, discussion-quiz.md 를 만든다.
  오늘 쓴 규칙을 그대로 지킨다: 지어내지 않기, [확인 필요] 표시, 출처 표시, 원본 메모 고치지 않기, 지우지 않기.
  실행 전에 계획부터 보여 준다.
  만든 자료는 초안이고, 마지막 확인은 내가 한다고 끝에 꼭 적는다.
----

[2] [직접] 스킬 파일 읽어 보기 (.claude 폴더가 숨겨져 있으면)
----
lecture-kit 스킬 파일을 메모장으로 열어줘
----
    □ 내가 말한 규칙이 다 들어 있나요?  □ 추가된 규칙에 동의하나요?

[3] 입력 칸에 /lec 까지 쳐서 목록에 /lecture-kit 이 보이는지 확인
    (안 보이면 /exit → 터미널에서 claude -c)


==================================================================
 STEP 6. 자동화: 새 자료가 들어오면 한 마디로 전부 (5분)
==================================================================

[1] 자동화 스킬 만들기
----
매주 쓸 자동화 스킬을 하나 더 만들어줘.
위치: .claude/skills/weekly-prep/SKILL.md
이름: weekly-prep
하는 일: /weekly-prep 다음주 주제 (예: /weekly-prep 8주차 피드백)
  1. practice/express30/inbox 폴더에 새로 들어온 메모가 있는지 스스로 찾는다. 없으면 없다고 말하고 멈춘다.
  2. 새 메모만 literature-table.csv 에 추가한다. 기존 행은 바꾸지 않는다.
  3. lecture-kit 스킬의 규칙 그대로 다음 주 주제의 수업 자료를 만든다.
  4. 처리한 메모는 inbox 에서 papers 폴더로 옮긴다. 지우지 않는다.
  5. 마지막에 '교수님이 확인하실 것' 목록을 한 화면으로 보여 준다: 새로 추가된 행, [확인 필요], 중복 의심, 쓰지 않은 항목.
  실행 전에 무엇을 할지 계획부터 보여 준다.
----

[2] 시험용 "새로 들어온 자료" 만들기
----
practice/express30/inbox 폴더에 지난번과 같은 분야, 같은 규칙으로 가상 논문 메모 2편(paper07.md, paper08.md)을 만들어줘. 그중 1편은 연도가 빠지게 해줘.
----
    (예비 자료로 하려면)
----
tutor/samples/express30/inbox 의 예비 자료를 practice/express30/inbox 로 복사해줘
----

[3] 한 마디로 실행 ([ ] 에 다음 주 주제)
----
/weekly-prep [다음 주 주제]
----

[4] 허락 화면에 삭제 명령(rm, del, Remove-Item)이 보이면 아니오 →
----
삭제하지 말고 옮기기만 해줘
----

[5] [직접] 탐색기에서 확인
    □ inbox 가 비고 papers 에 메모가 8개?
    □ 정리표에 새 행 2개, 연도가 빠진 메모는 [확인 필요]?
    □ 새 주제의 수업 자료 폴더가 생겼나요?

    이제 매주 할 일: 새 메모를 inbox 에 넣고 /weekly-prep 한 마디.

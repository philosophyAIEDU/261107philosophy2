사용법
- 아래 '----' 사이의 문장을 그대로 복사해 클로드 코드 입력창에 붙여 넣고 Enter.
- [ ] 안은 교수님 내용으로 바꿔도 됩니다.
- 모든 실습은 가상 자료로만 합니다. 실제 학생 정보는 넣지 않습니다.
- 실습 도우미를 쓰는 말: 다음 / 힌트 / 확인해 주세요 / 어디까지 했죠?

==================================================================
 실습 3. 폴더 정리 — 백업 · 계획 · 실행 · 검증
==================================================================

[STEP 2] 백업 — /exit 로 클로드를 끄고 터미널에서 직접
----
cp -R practice/03-folder-cleanup/lecture-materials practice/03-folder-cleanup/lecture-materials-backup
----
다시 켜기
----
claude -c
----

[STEP 3] 계획 모드(Shift + Tab → plan mode on)에서
----
practice/03-folder-cleanup/lecture-materials 폴더를 정리하고 싶어. 아직 실행하지 말고 계획만 세워줘.
- 주차별 폴더(week01 ~ week15)로 나누기
- 파일 이름 규칙: 주차_자료유형_제목.txt  예) week03_slides_공리주의.txt
  자료유형은 slides / quiz / reading / assignment / notice
- 중복으로 보이는 파일은 지우지 말고 _duplicates 폴더로 모으기
- 주차를 알 수 없는 파일은 _unsorted 폴더로
- 파일 이름과 내용의 주차가 다르면 스스로 정하지 말고 '확인 필요'로 표시
바꾸기 전/후 파일 이름을 표로 보여줘.
----

[STEP 4] 계획 고치기 (예시)
----
자료유형에 'activity'(수업 활동지)도 추가해줘. 그리고 '공지'는 주차 폴더 말고 _notices 폴더에 모아줘.
----

[STEP 5] 실행 중 삭제 명령이 보이면 아니오 →
----
삭제하지 말고 _duplicates 로 옮겨줘
----
불안하면 Esc →
----
지금까지 뭘 했는지 요약해줘
----

[STEP 6] 검증
----
정리 결과를 검증해줘.
- 백업 폴더(lecture-materials-backup)의 파일 개수와 정리 후 파일 개수가 같은지
- 백업에는 있는데 정리 후 사라진 파일이 있는지 (내용으로 대조)
- 이름 규칙을 안 지킨 파일 목록
- '확인 필요'로 표시한 파일 목록
----

[STEP 7] 기록 남기기
----
이번 정리 내역을 practice/03-folder-cleanup/cleanup-log.md 로 만들어줘.
날짜, 정리 규칙, 바뀐 파일 목록(전→후), 내가 확인해야 할 파일 목록을 포함해서.
----
폴더 매뉴얼 만들기
----
cleanup-log.md 의 규칙을 바탕으로 practice/03-folder-cleanup/CLAUDE.md 를 만들어줘.
파일 이름 규칙, 폴더 구조, '파일은 절대 삭제하지 말고 _duplicates 로 옮긴다'는 원칙을 넣어줘. 15줄 이내로.
----
----
/memory
----

 실습 4. 제출 현황표
==================================================================

[STEP 1] 백업
----
! cp -R practice/04-submissions/submissions practice/04-submissions/submissions-backup

[STEP 2] 계획 모드(plan mode on)에서
----
practice/04-submissions 의 과제1 제출물을 roster.csv 와 대조해서 정리하려고 해. 실행하지 말고 계획만 보여줘.
- submissions 폴더 안 파일 이름을 '학번_이름_과제1.txt' 로 통일
- 파일 이름에 학번이 없으면 파일 내용에서 학번을 찾아 판단
- 파일 이름과 내용의 학생 정보가 다르면 이름을 바꾸지 말고 '확인 필요' 목록에 넣기
- 같은 학생이 여러 번 냈으면 지우지 말고 둘 다 남기고 _1, _2 로 표시
- practice/04-submissions/submission-status.csv 만들기
  열: 학번, 이름, 제출여부, 제출일시, 지각여부, 파일명, 비고
  엑셀에서 한글이 깨지지 않게 UTF-8 (BOM) 으로 저장
- 마감: 2026-10-20 23:59 (23:59 제출은 정시로 본다)
----

[STEP 3] 미제출자가 계획에서 빠져 있다면
----

----

----

----

[STEP 5] 엑셀에서 한글이 깨지면
----
submission-status.csv 를 UTF-8 BOM 으로 다시 저장해줘
----

[STEP 6] 교수님 결정 기록하기 (예시)
----
submission-status.csv 에 '교수님결정' 열을 추가해줘.
- 2회 제출 학생: 마지막 제출본을 채점
- 지각 3명: 사유 확인 후 결정 (지금은 '사유 확인 중'으로)
- 확인 필요 파일: [교수님이 확인한 내용]

==================================================================
 실습 8. 내 업무 설계
==================================================================

[STEP 1] 설계 시트 인터뷰
----
나만의 자동화 설계를 도와줘. 아래 설계 시트 항목을 하나씩 나에게 질문해 줘. 한 번에 하나씩만 묻고, 내 답을 기다려 줘.
① 반복하는 업무 ② 얼마나 자주, 몇 개 ③ 입력(어떤 파일에서 시작) ④ 출력(어떤 파일이 나와야)
⑤ 규칙(이름, 형식, 기준) ⑥ 애매할 때는 나에게 넘길지, 규칙대로 처리할지 ⑦ 내가 검증할 방법
⑧ 개인정보가 들어가는지
다 끝나면 practice/08-my-automation/design-sheet.md 로 정리해줘.
----

[STEP 2] 스킬 초안 만들기
----
@practice/08-my-automation/design-sheet.md 를 바탕으로 스킬 초안을 practice/08-my-automation/my-skill/SKILL.md 로 만들어줘.
안전 규칙을 꼭 넣어줘: 삭제하지 말고 옮기기, 애매한 것은 [확인 필요]로 넘기기, 없는 정보 지어내지 않기.
----

 보너스 (수업 후 혼자 해 보기)

[B1] 회의록 4개 → 결정 사항·할 일 표

# 강사용 진행 가이드

## 이 저장소의 작동 방식

- 교수님이 `claude-lab` 폴더에서 `claude` 를 실행하면 루트의 `CLAUDE.md` 가 자동으로 읽혀, 클로드가 **실습 도우미(튜터) + 조교** 역할을 합니다.
- `/start`, `/next`, `/hint`, `/check`, `/progress`, `/stuck`, `/lab`, `/reset-lab` 은 `.claude/skills/` 에 있는 스킬입니다.
- 실습 도우미는 `tutor/labs/*.md` 안내서를 `### STEP` 단위로 한 단계씩 보여 주고, 진도는 교수님 폴더의 `my-progress.md` 에 저장합니다. (이 파일만 허락 없이 고치도록 `.claude/settings.json` 에 허용해 두었습니다)
- `/check` 는 `tutor/answer-keys/` 의 정답 기준(제출 26명, 지각 3명 등)과 실제 파일을 대조합니다.
- 실습 재료는 `practice/` 에 미리 들어 있고, 원본은 `tutor/starter/` 에 있어 `/reset-lab` 으로 되돌릴 수 있습니다.

## 기존 1~4편 txt 튜토리얼에서 바뀐 점

| 기존 | 바뀐 점 | 이유 |
|---|---|---|
| 매 편마다 클로드에게 가상 자료를 생성시킴 | 재료를 **미리 만들어** 저장소에 넣음 | 수업 시간 절약, 모든 교수님이 같은 자료 → 정답 대조 가능 |
| 교재를 읽으며 혼자 따라 함 | 클로드 안의 **실습 도우미**가 한 단계씩 안내, `/check` 로 결과 확인 | 강사 한 명이 여러 명을 돌볼 때 개별 진도 차이 해결 |
| 설치(1편)·터미널 기초(2편)를 수업에서 | 설치는 사전 과제, 터미널 기초는 클로드 안의 `!` 명령으로 | 1~2시간 안에 자동화까지 도달 |
| 폴더 정리 함정 없음 | 이름-내용 불일치, 수정본 vs 중복, '배포 금지' 파일 | 검증 단계에서 "AI도 틀린다"를 스스로 발견 |
| 제출물 함정: 지각·중복 | + 마감 정각 경계(23:59), 이름이 잘못 붙은 파일 | 경계 규칙을 미리 정하는 습관 |
| 공지문 생성 | + 계획서에 일부러 빈칸, "지어내지 마" 유무 비교 실험 | 환각을 눈으로 확인 |
| — | **새 실습**: `/rewind` 되돌리기, `claude -c`, `/memory`, `--permission-mode acceptEdits`, 스킬 직접 고치기, 내 업무 설계(실습 8), 보너스 4종 | CLI 기능을 고르게 익히고, 학교로 가져갈 결과물 만들기 |

## 수업 전 체크리스트 (1주 전 안내)

- □ 클로드 유료 계정 (Pro 이상) 확인
- □ 클로드 코드 설치 + 한 번 로그인 (README ① 단계)
- □ 실습실 내려받기 (README ② 단계) — 수업 당일 와이파이가 불안하면 USB 로 ZIP 배포
- □ 노트북 충전기

## 시간표

### 30분 (핵심 코스, `tutor/labs/express30.md`)
| 시간 | 내용 |
|---|---|
| 0:00–0:03 | `cd ~/claude-lab` → `claude` → `/start` → **1. 30분 핵심 코스** |
| 0:03–0:07 | STEP 1 기본 명령 (작업실 확인, Shift+Tab, Esc, `/`, `@파일`, `/rewind`) |
| 0:07–0:12 | STEP 2 전공을 묻고 가상 논문 메모 6편 만들기 |
| 0:12–0:17 | STEP 3 계획 모드로 문헌 정리표 → 원문과 대조 |
| 0:17–0:23 | STEP 4 수업 자료 (HTML 슬라이드, 노트, 토론·퀴즈) + 한 군데 고치기 |
| 0:23–0:27 | STEP 5 `/lecture-kit` 스킬 저장 |
| 0:27–0:30 | STEP 6 `/weekly-prep` 자동화 · STEP 7 근육 체크 |

설치·로그인은 반드시 사전 과제로 받아 두세요. 이 코스는 `!` 명령과 `claude -p` 를 쓰지 않습니다. 교수님 전공으로 가상 자료를 만들기 때문에 결과가 사람마다 다릅니다. 자료 만들기가 막히면 예비 자료(`tutor/samples/express30/`)를 복사해 진행합니다. .pptx 는 Python 이 있는 분만 선택으로 합니다. 시간이 빠듯하면 STEP 6은 강사 시연으로 대체합니다. 다시 하실 분은 `/reset-lab 30` 으로 작업장을 되돌립니다.

### 90분
0 → 1 → 2 → 3 → 4 → 6 → 8 (실습 5·7은 과제). 실습 6은 실습 5를 건너뛰어도 진행 가능.

### 60분
0 → 1 → 2 → 4 → 6. 실습 3은 강사 시연 5분으로 대체하고 혼자 해 보시도록 안내.

## 진행 팁

- 시작할 때 교수님들께 `/start` 에서 수업 시간(30분 핵심/60/90/120분)을 고르시게 하면 실습 도우미가 그 경로로 안내합니다.
- 진도가 앞선 분은 보너스(`/lab bonus`)로, 늦은 분은 강사가 `/lab N` 으로 같은 지점에 맞추게 합니다.
- 결과가 사람마다 조금씩 다른 것이 정상입니다. "왜 다를까?"가 좋은 토론 거리입니다 (확률).
- 허락 화면 문구, 모드 표시 문구는 클로드 코드 버전마다 조금 다릅니다. 시작 전에 강사 컴퓨터에서 한 번 돌려 보세요.
- Windows 에서 `!` 명령은 클로드 코드가 쓰는 셸(PowerShell 또는 Git Bash)에서 실행됩니다. 안내서의 명령은 두 셸 모두에서 동작하도록 골랐습니다 (`cp -R`, `ls`, `start notepad`, `explorer "..."`).

## 실습 재료 다시 만들기 (강사용)

재료를 바꾸고 싶으면 `instructor/tools/make_materials.py` 를 고친 뒤:
```
python -X utf8 instructor/tools/make_materials.py
```
`tutor/starter/` 와 `practice/` 가 새로 만들어집니다. 정답 기준(`tutor/answer-keys/`)도 함께 고쳐 주세요.

## 개인정보 원칙 (수업에서 꼭 한 번 강조)

- 모든 실습 자료는 가상입니다 (학생01~학생30, 2026-0001~0030).
- 실제 학생 자료를 쓰기 전에: 소속 대학 AI 활용 지침 확인 → 가명 처리 → 꼭 필요한 열만.
- 실습 도우미는 실제 개인정보로 보이는 내용이 나오면 작업을 멈추고 안내하도록 설정되어 있습니다 (`CLAUDE.md` 5절).
